### 4.3 代价判定说明

- 三域共 47 条，**高代价 0 条**。原因是三域的知识主体是 Token、CSS 布局、文案表与验收脚本，不需要完整平台 token 集、非标准渲染或键盘+浮层+虚拟化的复合交互。
- 被评为「中」的 16 条，均命中总清单「中」判定口径之一：虚拟化（滚动容器）、浮层与焦点（焦点顺序）、双主题双实例（深浅主题可读性）、状态模型（导航模型、信息架构层级）、多档联动（密度模式）、i18n 库（国际化与本地化）。
- 未出现「—」：三域全部可在现有技术栈约束内找到实现路径，无需标注无法判定。
