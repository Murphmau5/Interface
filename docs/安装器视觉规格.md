> 版本：v0.1（2026-11-09）· 状态：待评审（未动代码，未执行任何构建）
> 范围：Windows NSIS 安装程序 + 卸载程序的页面流程与视觉规格。

## 0. 一句话结论

网易云音乐 Windows 安装器的做法是**「一屏搞定 + 原地向下展开」**：不设欢迎页、不设独立目录页、不设协议页，首页就把「图标 + 一个主按钮 + 一行协议勾选 + 一个『自定义安装』折叠区」放在同一屏，进度页只留一条极细进度条配品牌内容，完成页只剩一个大对勾和一个「立即体验」。

我们照抄的是这套**信息压缩与省略**，不照抄它的红色品牌、演唱会实拍背景与捆绑推广勾选。落地方式建议分两级：**方案 A（推荐，低风险）**用 MUI 自定义页重排页面顺序、保留 NSIS 原生安装引擎与进度/取消能力；**方案 B（高保真，不建议进 1.0.x）**整窗自绘 500×300 单页面。两者差异见 §7。

## 1. 证据等级与查证程度

本文所有结论按四级标注，不混用：

| 标记 | 含义 |
|---|---|
| 【实测】 | 有 1:1 截图，尺寸/颜色由像素量取得出（有 ±1–2px 误差） |
| 【推断】 | 从截图可直接看出，但没有数值证据（如「圆角是胶囊形」但未量半径） |
| 【通识】 | 行业公开做法或官方文档描述，本次**未**逐屏截图核验 |
| 【待验证】 | 需要真实构建 + 运行安装包才能确认，本文只给方案 |

### 1.1 网易云音乐（主参考）

- 查证来源：ZOL 安装教程《电脑版网易云音乐怎么下载安装》（2025-03-28），含 5 张流程截图；华军软件园《网易云音乐安装步骤》（文字描述）。
- 查证程度：**截图核验 + 像素量取**。截图来自第三方教程站，已被裁切到窗口范围，且可能经过缩放，因此尺寸按「比例 + 相对关系」使用，绝对值标 ±2px。
- 未核验：该安装器的内部实现（是否 NSIS）、版本号对应关系、键盘/无障碍行为、多语言、静默安装参数。**不编造。**

### 1.2 同类对照（只取可迁移点）

| 产品 | 安装器形态 | 可迁移点 | 查证程度 |
|---|---|---|---|
| Visual Studio Code（Windows） | Inno Setup 经典向导：许可 → 目录 → 开始菜单 → 附加任务 → 安装 → 完成 | 「附加任务」页把多个勾选项集中在一页，默认勾选常用项；完成页「启动」勾选 | 【通识】官方文档列出的安装选项，未截图核验 |
| Figma / Discord（Windows） | 无向导，静默安装到用户目录后直接启动 | 「零决策安装」是可接受的现代做法，但会失去路径与快捷方式控制 | 【通识/推断】安装包行为的公众认知，未核验 |
| 网易云音乐 | 单窗口原地展开，无独立向导页 | 折叠式高级选项；进度页用品牌内容替代技术细节 | 【实测】见 §2 |

结论：**没有独立欢迎页**是三者共同趋势；VS Code 保留多页是因为它的「附加任务」有 5 项真实可选行为，而我们只有 1–2 项，多页没有信息量支撑。

## 3. 可迁移与不照抄

**要迁移（4 条）**

1. **删除独立欢迎页**：欢迎页对用户零信息量，纯占一次点击。
2. **删除独立目录页**：路径改为首页折叠区（默认路径直接可见，改路径才展开）。
3. **进度页克制**：一条细进度条 + 一句阶段文案，明细日志默认隐藏（出错时需要能展开）。
4. **完成页只留一个动作**：启动/不启动用一个勾选表达，不堆按钮。

**不照抄（5 条）**

1. **品牌红**：用我们的 `accent`（深色浅青 `#7FD3E8` / 浅色深青 `#0E7A8A`）。
2. **演唱会实拍背景**：安装包内不得含第三方照片（宪法 §15.3），改自绘网格/噪点或纯色。
3. **捆绑推广勾选**（开机启动、默认播放器、第三方组件）：与我们产品无关，且损害信任，一律不做。
4. **无取消按钮的进度页**：NSIS 原生给取消能力，保留。
5. **单按钮完成页**：NSIS 完成页按钮文案受语言表控制，不为此自绘整页（见 §7.5 的取舍）。

## 5. 尺寸与层级规格

坐标一律按 **96dpi 像素**给出。NSIS 自定义页使用 Dialog Unit，落地时需换算并在真机校正（见 §7.4）。

### 5.1 窗口与分区

| 项 | 数值 | 依据 |
|---|---|---|
| 窗口尺寸（方案 B） | 500 × 300 紧凑 / 500 × 446 展开 | 对齐网易云【实测 500×302 / 500×447】 |
| 窗口尺寸（方案 A） | 沿用 MUI2 默认 ≈503×386 | 不改向导尺寸，避免布局碎裂【待验证】 |
| 标题条高度 | 32（紧凑）/ 36（触控） | 网易云 ≈32–36【推断】 |
| 标题条内边距 | 左右 16 | 视觉对齐，与窗口 20px 内容边距区分 |
| 标题条字号 | 12 / 400 / textSecondary | 与 `--font-size-meta` 一致 |
| 关闭按钮 | 32 × 32 命中区，图标 10×10 线宽 1.5 | 与 H-UI §7.5 图标规范一致 |
| 内容左右边距 | 20 | 网易云复选行左起点 20【实测】 |
| 内容顶部到图标 | 24 | 【推断】 |
| 分区间距 | 16 / 24（小/大） | `--space-4` / `--space-6` |
| 展开区新增高度 | 144 | 网易云 +145【实测】 |

### 5.2 字号阶梯（只允许这 6 级）

| 级别 | 字号/行高 | 字重 | 用途 | Token |
|---|---|---|---|---|
| Hero | 26 / 32 | 600 | 「安装完成」 | `--font-size-hero` |
| Display | 20 / 26 | 600 | 屏 1 产品名 | `--font-size-display` |
| Title | 15 / 22 | 600 | 分区标题（安装位置） | `--font-size-title` |
| Body | 13 / 20 | 400 | 正文、复选文字 | `--font-size-body` |
| Meta | 12 / 18 | 400 | 版本号、空间数值、阶段文案 | `--font-size-meta` |
| Label | 11 / 16 | 400，字距 0.08em | 全大写英文标签（仅 `INTERFACE` 副标） | `--font-size-label` |

- 标题字距 `-0.01em`（`--tracking-tight`），正文 `0`。
- 数字（空间、版本、百分比）用等宽数字。
- 字体只用系统栈：`"Segoe UI Variable Text", "Segoe UI", "Microsoft YaHei UI", system-ui`。中文回退 `Microsoft YaHei UI`，**不打包字体**（宪法 §8）。

### 5.3 灰度关系（三层，不允许第四层）

| 层 | Token | 用途 | 对比度要求 |
|---|---|---|---|
| 主文字 | `textPrimary` | 产品名、屏 3 标题、按钮文字（非强调底） | ≥ 4.5:1 |
| 次文字 | `textSecondary` | 一句话定位、复选文字、路径值 | ≥ 4.5:1 |
| 辅助文字 | `textTertiary` | **禁止用于正文**；仅装饰性版本前缀 | 见下 |

> **偏差提醒**：`textTertiary` 在浅色 `#7C8B99` on `#F5F8FA` 约为 3.3:1，不满足 11–12px 正文字号 AA。因此安装器里**版本号、空间数值一律用 `textSecondary`**，`textTertiary` 只留给「v」前缀这类可忽略字符。这是对 H-UI §7.2 的收紧，不改 Token 值。

### 5.4 按钮规格

| 类型 | 尺寸 | 形态 | 深色 | 浅色 |
|---|---|---|---|---|
| 主按钮（立即安装 / 完成） | 高 36，最小宽 160，左右内边距 24 | 圆角 8（方案 A）/ 胶囊（方案 B 仅自绘可达） | `accent` 底 + `accent-ink` 文字 | `accent` 底 + `accent-ink` 文字 |
| 主按钮 hover | — | 底提亮 8%，120ms | `accent` → `accentPressed` | `accent` → `accentPressed` |
| 主按钮 disabled（协议未勾选） | — | 40% 不透明，不可点 | — | — |
| 次按钮（浏览 / 取消） | 高 28，内边距 16 | 圆角 6，`surfaceRaised` + `border` | 见 §6 | 见 §6 |
| 文字链接（自定义安装 / 查看许可） | 行高 20，无底 | 下划线仅 hover 出现 | `textSecondary` → `accent` | 同 |

- 主按钮**只有一处**：每屏最多一个实心强调按钮（H-UI §7.2「accent 只用于当前状态与主行动」）。
- 按钮位置：居中（屏 1、屏 3，对齐网易云）；若走方案 A 则受 MUI 布局约束，只能右下角。

### 5.5 控件细节

| 控件 | 规格 |
|---|---|
| 复选框 | 16×16，圆角 3，勾选 `accent` 填充 + `accent-ink` 勾；文字 13px `textSecondary`，与框间距 8 |
| 输入框（安装路径） | 高 28，`surface` 底 + 1px `border`，内边距 8，等宽/正文 13px，只读感但可编辑 |
| 进度条 | 高 3，圆角 2（`radius-pill` 语义），槽 `border`，填充 `accent`；左右内边距 20 |
| 图标 | 84×84，圆角 20，不使用投影 |
| 分割线 | 1px，`border` 合成色（见 §6.3） |
| 对勾图标 | 44×44 圆环，线宽 2，`accent` |

### 5.6 背景

- 方案 A/B 均建议**纯 `bg` 或 `surface` 单色**，可选叠加自绘「仪器台网格」：1px 线，间距 32，透明度 3.5%（`--grid-line` 同源），只出现在顶部 160px 内并向下淡出。
- **禁止**：实拍照片、渐变光晕、霓虹、第三方插画（宪法 §15.3）。

## 6. Token 映射（安装器不支持 CSS，需硬编码取值）

安装器是原生 Win32 对话框，无法消费 CSS 变量。下表是**语义 Token → 安装器实值**的唯映射表，实现时代码里只允许引用这张表，不得另造颜色。

### 6.1 深色（`data-theme="dark"` 对应）

| 语义 Token | RGB | BGR（`SetCtlColors` / `System::Call` 用） | 用途 |
|---|---|---|---|
| `bg` | `#07090C` | `0C0907` | 页面底色 |
| `surface` | `#0B1014` | `14100B` | 输入框底、分区底 |
| `surfaceRaised` | `#10161C` | `1C1610` | 次按钮底 |
| `textPrimary` | `#E8EEF3` | `F3EEE8` | 主文字 |
| `textSecondary` | `#97A5B2` | `B2A597` | 次文字、复选文字 |
| `textTertiary` | `#5F6E7B` | `7B6E5F` | 仅装饰性前缀 |
| `accent` | `#7FD3E8` | `E8D37F` | 主按钮底、进度填充、勾选 |
| `accentPressed` | `#A6E3F3` | `F3E3A6` | hover 提亮（见注 1） |
| `accent-ink` | `#041417` | `171404` | 主按钮文字 |
| `statusDanger` | `#DF8B8B` | `8B8BDF` | 错误提示文字（仅错误态） |

### 6.2 浅色（`data-theme="light"` 对应）

| 语义 Token | RGB | BGR | 用途 |
|---|---|---|---|
| `bg` | `#EEF2F5` | `F5F2EE` | 页面底色 |
| `surface` | `#F5F8FA` | `FAF8F5` | 输入框底 |
| `surfaceRaised` | `#FFFFFF` | `FFFFFF` | 次按钮底 |
| `textPrimary` | `#14202B` | `2B2014` | 主文字 |
| `textSecondary` | `#546575` | `756554` | 次文字 |
| `textTertiary` | `#7C8B99` | `998B7C` | 仅装饰性前缀 |
| `accent` | `#0E7A8A` | `8A7A0E` | 主按钮底、进度填充 |
| `accentPressed` | `#0A6272` | `72620A` | 按下态（**比 hover 更深**，浅色语义相反） |
| `accent-ink` | `#F4FCFD` | `FDFCF4` | 主按钮文字 |
| `statusDanger` | `#A63C3C` | `3C3CA6` | 错误提示文字 |

> 注 1：深色主题的「按下」是提亮（`accentPressed` 更亮），浅色主题的「按下」是加深。这与 H-UI §7.2 取值一致，**不是反色推导**。
> 注 2：`accent`/`accentPressed` 的 BGR 换算：`#7FD3E8` → `E8 D3 7F`；`#0E7A8A` → `8A 7A 0E`。实现时用脚本换算，不手抄。

### 6.3 半透明 Token 的落地（Win32 不支持 alpha）

`border` / `borderStrong` / `accentSoft` 在 CSS 里是带 alpha 的。安装器里必须**预合成到实色**：

| Token | 深色（合成到底色） | 浅色（合成到底色） |
|---|---|---|
| `border` | `#1A1E22`（白 6% over `#0B1014`） | `#E7E9EB`（墨 10% over `#FFFFFF`） |
| `borderStrong` | `#282D30`（白 12% over `#0B1014`） | `#D4D8DB`（墨 18% over `#FFFFFF`） |
| `accentSoft` | `#172429`（青 10% over `#0B1014`） | `#ECF4F6`（深青 8% over `#FFFFFF`） |

- 这三个是**派生合成值，不是新颜色**；若主题层改值，必须同步重算。
- 位图资源里的描边也按此值预渲染，不要在运行时叠加。

### 6.4 主题跟随策略

| 选项 | 做法 | 代价 | 建议 |
|---|---|---|---|
| A. 固定浅色 | 只做浅色一套资源 | 与深色系统不协调 | 可用，最省 |
| B. 跟随系统 | 读 `HKCU\...\Themes\Personalize\AppsUseLightTheme`（1=浅 0=深），加载对应位图 | 资源翻倍；MUI 的 `MUI_*_BITMAP` 是**编译期常量，不能运行时切换**，必须走自定义页 + 运行时 `LoadImage` | 推荐（与产品「默认跟随系统」一致） |
| C. 固定深色 | 只做深色一套 | 违反 Windows 安装器惯例，浅色系统用户刺眼 | 不推荐 |

> 需拍板。若选 B，屏 1/屏 3 必须自绘（MUI 宏无法切图），实现复杂度显著上升；若选 A，屏 1 仍可用自定义页但只需一套 BMP。

### 7.2 目标页面顺序（方案 A）

```
R0  维护页        Page custom PageReinstall ...        （保留 L228，仅改文案与配色）
屏1 Page custom PageInstallOptions                     （新增，替换 WELCOME + DIRECTORY）
屏2 MUI_PAGE_INSTFILES                                 （保留，隐藏明细、改配色、加 header 位图）
屏3 MUI_PAGE_FINISH                                    （保留，改勾选与文案）
```

**要动的 5 处**

1. **删除** `MUI_PAGE_WELCOME`（L170–171）→ 换 `Page custom PageInstallOptions PageInstallOptionsLeave`。
2. **删除** `MUI_PAGE_DIRECTORY`（L422–424），路径控件并入屏 1。`$INSTDIR` 的默认值逻辑保留在 `.onInit`（[L542–561](../src-tauri/installer.nsi#L542-L561)）**不动**，屏 1 只负责展示与覆盖。
3. **保留** `MUI_PAGE_STARTMENU` 的 `Skip` 分支（当前即隐藏），不改。
4. **保留** `MUI_PAGE_INSTFILES`，仅做视觉改写（§7.4）。
5. **保留** `MUI_PAGE_FINISH`，把「创建桌面快捷方式」的 `SHOWREADME` 复用改为真正的选项传递，避免完成页出现两个勾选。

**不得动**（否则破坏发布链）：`{{#if signed_plugins_path}}`、`{{#if installer_hooks}}`、`NSIS_HOOK_PREINSTALL/POSTINSTALL/PREUNINSTALL/POSTUNINSTALL`、`SkipIfPassive` 系列、`$PassiveMode/$UpdateMode/$NoShortcutMode/$WixMode` 语义、`.onInit` 的降级拦截（[L564–592](../src-tauri/installer.nsi#L564-L592)）。

### 7.3 屏 1 自定义页要点（`PageInstallOptions`）

| 步骤 | 做法 |
|---|---|
| 建页 | `nsDialogs::Create 1018`，`Pop $0`；`SetCtlColors $0 <bg> <bg>` 铺底色 |
| 图标 | `nsDialogs::CreateControl STATIC ${SS_BITMAP} ...` + `SendMessage ... ${STM_SETIMAGE} ${IMAGE_BITMAP} $hBmp`（`$hBmp` 由 `LoadImage` 得到） |
| 产品名/一句话/版本 | 三个 `STATIC`，分别 20/13/12px；字号通过 `CreateFont`（`System::Call gdi32::CreateFont`）或直接 `WM_SETFONT` 复用 `$HWNDPARENT` 字体后放大 |
| 协议复选 | `BUTTON` + `${BS_AUTOCHECKBOX}`，`NSD_OnClick` 里 `EnableWindow` 主按钮 |
| 折叠区 | 用一个 `Var` 记录展开态，点击「自定义安装」`NSD_OnClick` → `ShowWindow` 各控件 + `SendMessage $HWNDPARENT ${WM_COMMAND} ...` 触发重排；或直接分成两屏（更简单但失去「原地展开」观感） |
| 路径编辑 | `EDIT`（`${ES_AUTOHSCROLL}`）+ 「浏览」`BUTTON` → `nsDialogs::SelectFolderDialog "选择安装位置" "$INSTDIR"`，回填 `$INSTDIR` |
| 空间校验 | `${DriveSpace}` 取可用空间，`${GetSize}`/`{{estimated_size}}` 取所需；不足时把主按钮置灰并给 `statusDanger` 提示 |
| 主按钮文案 | `GetDlgItem $0 $HWNDPARENT 1` → `WM_SETTEXT` 改「立即安装」；`GetDlgItem $0 $HWNDPARENT 3` 改「退出」 |
| 校验失败返回 | `PageInstallOptionsLeave` 里 `Abort` 并聚焦错误控件 |

**已知技术限制（必须写进代码注释）**

- `SetCtlColors` **不改写带视觉样式的 BUTTON**（Win10/11 按钮由主题绘制）。要完全控制按钮底色，需要 `SetWindowTheme(hwnd, "", "")` 关闭主题 + 自绘，属高风险。**方案 A 接受系统按钮样式**，只改文字与背景。
- STATIC 位图**只支持 BMP / ICO，不支持 PNG**。
- 位图**不随 DPI 缩放**；PerMonitorV2 下 150% 会糊。要么按当前 DPI 选不同位图（`GetDpiForWindow` + 分支），要么接受。
- 自定义页坐标是 DLU 不是 px，需换算后真机校正（可复用 [L464–492](../src-tauri/installer.nsi#L464-L492) 的 DPI 除法写法）。

### 7.4 屏 2（安装中）改写

- 保留 `MUI_PAGE_INSTFILES` 的原生进度与取消能力（这是不选自绘页的核心理由）。
- 视觉：
  - `!define MUI_HEADERIMAGE` + `MUI_HEADERIMAGE_BITMAP` 放 150×57 品牌条；
  - `GetDlgItem $0 $HWNDPARENT 1016`（明细列表）→ `ShowWindow $0 0`，把进度区上移；
  - 进度条色：`MUI_INSTFILESPAGE_PROGRESSBAR colored` 的取色受 MUI 版本影响，**若实测无法指定为 `accent`，就接受系统色**，不要为了染一条 3px 的线去自绘整个页面；
  - 阶段文案用 `DetailPrint` 之外的 `SetCtlColors`/静态标签不现实，改用 `MUI_INSTFILESPAGE_FINISHHEADER_TEXT` 与 `DetailPrint` 兼顾。
- 【待验证】隐藏列表后进度条不重排 —— 必须在真实构建中看一眼，若错位则退回「保留列表、仅换头图」。

### 7.5 屏 3（完成）改写

- 保留 `MUI_PAGE_FINISH`。
- `MUI_FINISHPAGE_RUN` + `MUI_FINISHPAGE_RUN_TEXT "立即体验 界序 INTERFACE"`（勾选默认选中；如需强制默认勾选，不要加 `MUI_FINISHPAGE_RUN_NOTCHECKED`）。
- 去掉 `MUI_FINISHPAGE_SHOWREADME`（桌面快捷方式已挪到屏 1），否则完成页出现两个勾选，与网易云的「单动作完成页」相悖。
- **取舍**：MUI 的完成按钮文案是 `$(^Finish)`（「完成」），语言表里是全局的，改成「立即体验」会同时影响卸载器。**不改**，接受「完成 + 立即体验勾选」。若要单按钮「立即体验」，只能走方案 B 自绘页面。
- 建议在完成页加一个静态链接「查看 MIT 许可」→ `ExecShell "open" "$INSTDIR\LICENSE"`（依赖 §8.2 的资源项）。

### 7.6 维护页与卸载器

- 维护页（降级）：保留全部判断逻辑，只改：
  - `MUI_HEADER_TEXT` 文案 → 「已安装 界序 INTERFACE」/「选择安装方式」；
  - `SetCtlColors` 设为当前主题底色与文字色；
  - 单选按钮文案沿用 LangString，不硬编码。
- 卸载器：`MUI_UNPAGE_CONFIRM` + `MUI_UNPAGE_INSTFILES` 保留；「删除应用数据」复选框位置沿用 [L464–492](../src-tauri/installer.nsi#L464-L492) 的 DPI 计算，只换配色。文案必须明确「删除后本地知识库与设置不可恢复」。

### 7.7 方案 B（高保真单页，不建议 1.0.x 采用）

- 全部页面 `Page custom` 自绘，窗口 `System::Call user32::SetWindowPos` 改为 500×300；胶囊按钮用 `BS_BITMAP` 三态位图（normal/hover/pressed）或 `BS_OWNERDRAW` + `WM_DRAWITEM`。
- 安装动作需从自定义页驱动（把 Section 体抽成 `Function DoInstall`，Section 与自定义页都 `Call` 它，完成后 `PostMessage $HWNDPARENT ${WM_COMMAND} 1 0` 前进），会**失去 NSIS 原生进度/取消语义**。
- 与 Tauri 模板升级冲突面大（模板是生成物）。**结论：除非要做品牌发布物料，否则不选。**

## 9. 验收清单

1. 交互安装路径：屏 1 → 屏 2 → 屏 3，**不出现** MUI 默认欢迎页与独立目录页。
2. 屏 1 未勾选协议时主按钮不可点；勾选后可点。
3. 屏 1 折叠区展开后窗口内容整体下移，不出现裁切/重叠（96dpi 与 150% 各看一次）。
4. 路径非法/空间不足时给出可读错误，主按钮置灰。
5. 屏 2 可取消，取消后不留半装文件与注册表项（沿用现有行为）。
6. 屏 3 勾选「立即体验」后应用启动，安装器退出。
7. 静默 `/S`、被动 `/P`、更新 `/UPDATE` 三条路径行为与改动前**完全一致**。
8. 降级场景仍走维护页，文案含真实旧版本号（现有 `$R5` 逻辑不得回退）。
9. 卸载器保留「删除应用数据」勾选，文案含不可恢复提示。
10. 深浅两套（若做）在对应系统主题下文字对比度 ≥ 4.5:1，无「黑底黑字」残留。
11. 安装包内无任何第三方图片/照片/插画（对照 §2 的网易云背景照片，明确不复用）。
