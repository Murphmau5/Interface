# v1.0.2 — 中文搜索与素材审核版

**发布日期**：2026-11-09
**发布类型**：功能版
**适用平台**：Windows 10 1803+ / Windows 11（x64）
**状态**：已发布（GitHub Releases，附件为 NSIS 安装包，未签名）

## 摘要

本版把「搜索、标签、合集、素材、候选」从占位入口变成可用的本地能力：中文搜索默认只查本地，标签与合集真正落库，素材按内容哈希存进对象目录，候选必须人工审核才能进案例库，导出一次同时产出 Markdown 与 JSON。列表与候选返回体改为按字节封顶，不再随条数无声膨胀。

## Added

1. 中文搜索本地优先：`LIKE` + 拼音物化列（全拼 + 首字母），默认作用域为本地，不联网。
2. 搜索作用域两个：本地（默认）与联网（`Ctrl+Enter`）；未配置 Key 时联网入口降级为「粘贴网址登记候选」，不自动发请求。
3. 拼音覆盖全拼与首字母：`按钮` / `anniu` / `anni` 都能命中，「按钮」「动效」「卡片」等二字高频词全部可用。
4. 标签落库：可给案例增删标签，去重并限 12 个；标签计数由 SQL 统计。
5. 合集落库：可新建合集、把案例加入/移出合集，左栏底部可直接进入合集视图。
6. 收藏与最近使用沉到左栏底部，作为视图而非分类，计数同样来自 SQL（最近按近 30 天更新）。
7. 筛选唯一状态：类型 / 平台 / 置信度 / 组件层，可组合、可重置，并带排序（更新 / 创建 / 标题）。
8. 网格与表格双视图，表格新增「平台」列；长列表沿用固定行高虚拟滚动。
9. 素材按 sha256 内容寻址导入：`objects/<前2>/<3-4>/<sha>.<ext>`，同一文件只存一份，引用去重。
10. 素材导入逐文件返回结果：超限、不可读、类型不支持都有可读错误，不再静默吞掉。
11. HTML 导入只做「存下来 + 标记未清洗」，本版不执行任何导入的 HTML。
12. `candidates` 候选池：支持登记、通过、拒绝、编辑后入库；只允许 pending → approved / rejected。
13. **没有免审开关**：任何来源（手工 / 网址 / 导入 / 搜索）的候选都必须经过一次显式审核才能进案例库。
14. 导出改为一次操作同时产出 Markdown 与 JSON，文件名带版本与日期（`<slug>-v1.0.2-YYYYMMDD`）。
15. 新增 `platform` 与 `component_layer` 字段；组件类案例按类目自动推导层级（atom / pattern）。

## Changed

- 列表与候选返回体按**字节预算**截断：案例列表累计 payload ≤ 8 MB，候选 ≤ 4 MB；标签 / 合集 / 素材每个列表 ≤ 500 行（每行约 120–300 B，折合 ≤ 150 KB）。
- 总数、分面、收藏 / 最近、合集与标签计数全部由 SQL 返回，前端不写死任何数字。
- 删除无效的 `search_text` 索引：`LIKE '%kw%'` 用不到它，只占磁盘与页缓存。

## Performance

### 为什么不上 FTS5

先在 1 万条假数据上做了基线实测（debug 构建，SQLite 内存库，70 次采样，`LIKE '%kw%'` + 拼音列）：

| 指标 | 实测 |
|---|---|
| P50 | 8.744 ms |
| P95 | **15.545 ms** |
| max | 17.250 ms |

高频二字词单项耗时：按钮 9.30 ms、动效 9.23 ms、卡片 8.54 ms、开关 8.98 ms、玻璃 8.79 ms、反馈 8.66 ms、主题 9.29 ms；三字「微交互」17.25 ms；首字母「an」16.98 ms。

P95 为阈值 80 ms 的约五分之一，且数据量再翻 10 倍仍有余量。FTS5 需要额外维护一张倒排表 + 写入时切重叠二元组，带来写放大与索引内存占用，在当前的实测数值下没有收益，因此本版**不引入 FTS5**，保留物化列方案。后续数据量到 10 万条会按同一方法重测再决定。

### 其他

- 搜索不驻留索引：拼音只在写入时计算并落到两列文本，查询期零额外内存。
- 素材导入按文件逐个读取，单文件上限 32 MB、单批 20 个，峰值内存由单文件上限决定，不随批量累积。

## Known Issues

- 搜索仍是全表 `LIKE` 扫描；数据量再上 10 倍需要重测。
- 标签目前只作案例元数据，尚无「按标签浏览」的独立入口。
- 类目覆盖仍是既定 36 条；类目之外的范围（如业务场景、行业）不在本版支持范围。
- 沙箱预览未做：导入的 HTML 只存储不执行，尚无隔离渲染沙箱。
- 安装包**未做代码签名**，首次运行可能触发 Windows SmartScreen；请核对 SHA-256 后选择「仍要运行」。
- 导出成功后只显示文件路径文本，暂无「打开所在文件夹」按钮。
- 仅提供 Windows x64；macOS 未验证。
- 重新打包前必须先关闭正在运行的 exe，否则 bundler 重命名二进制会报「拒绝访问」。
