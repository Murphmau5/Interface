# v1.0.3 — 安装器升级路径修正

这一版只做一件事：让旧版本上的用户能正常覆盖升级，不再被安装器拦下来做二选一。

## 问题与根因

### 1. 升级时弹出「已安装」选择页

安装器模板里 `PageReinstall` 页的触发条件是「同 `productName` 的卸载注册项存在」：

```
ReadRegStr $R0 SHCTX "Software\Microsoft\Windows\CurrentVersion\Uninstall\${PRODUCTNAME}" ""
```

只要 `HKCU\...\Uninstall\界序 INTERFACE` 存在，这个自定义页就会被挂进向导。旧模板随后用 `SemverCompare` 判断版本，但**升级分支（返回 1）也照样展示了该页**，并要求用户在「安装前卸载 / 请勿卸载」之间手动选择。

结论：判定依据是同产品名的卸载注册项，不是 AppId / upgradeCode 不匹配，也不是被当成了另一个程序。覆盖安装本身一直是同一套安装位置与注册项。

### 2. 「版本为 旧的 的」

旧模板在比较版本前执行了：

```nsis
StrCpy $R4 "$(older)"
```

`$(older)` 是本地化词条，简体中文即「旧的」。中文文案把 `$R4` 直接当作版本号内插，真正的旧版本号 `DisplayVersion` 在 `$R0` 里随后被 `Pop $R0` 覆盖，于是页面上出现了「系统中已存在版本为 旧的 的 …」。

## 本版改动

- 升级与同版本重装：不再显示选择页，自动静默卸载旧版本后继续安装，双击新包一路装完。
- 卸载失败或旧程序文件仍被占用：弹出可读提示后退出安装，不留半装状态。
- 旧版本程序正在运行：交互安装先提示「正在运行，确定关闭并继续 / 取消退出安装」，不会在用户不知情时强杀；静默安装沿用卸载器的强制结束进程行为，保证无人值守升级不中断。
- 降级仍然提示，但文案改用真实 `DisplayVersion`（读不到时显示「未知」），不再出现「旧的」占位符。
- 版本号同步至 1.0.3（`package.json` / `tauri.conf.json` / `Cargo.toml` / `Cargo.lock` / 关于页与左栏兜底值）。

## 验证方式与结果

全程静默安装，不依赖界面点击：

1. 隔离数据目录（把真实数据目录整体改名备份），避免污染本机已有数据。
2. 静默安装 1.0.0 到临时目录（`/S /D=...`，退出码 0），启动后用 IPC 写入一条标题为「升级前写入」的案例。
3. 关闭进程，对**同一目录**静默安装 1.0.3，退出码 0。
4. 结果核对：
   - exe `FileVersion` = `1.0.3`；卸载注册项 `DisplayVersion` = `1.0.3`。
   - 卸载注册项只有 **1** 条（没有并排两份）。
   - 启动后 `_sqlx_migrations` 为 `(1, init)(2, seed examples)(3, categories)(4, library)`，全部 success。
   - 「升级前写入」仍在（搜索结果 1 条），案例总数 6（5 条种子 + 1 条标记）。
   - `catalog_list` 返回 5 个类目；`tags_list` / `collections_list` 可正常调用（证明 0004 已生效）。
5. 反例：exe 正在运行时再次静默覆盖安装 —— 退出码 0，应用被 Restart Manager 强制关闭，安装完成后 exe 仍为 `1.0.3`、注册项仍为 1 条，可再次启动。运行中执行交互安装时，会先出现上文所述的可读确认提示。
6. 清理：静默卸载、删除临时目录、还原真实数据目录 / 注册表 / 快捷方式，确认本机原有 1.0.0 安装记录与安装位置未被破坏。

## 升级须知

- **直接双击 1.0.3 安装包即可覆盖升级**，不需要先卸载 1.0.0 / 1.0.2，也不需要手动选择。
- 升级前最好关闭正在运行的「界序 INTERFACE」。不关也能装：交互安装会先询问，静默安装会强制结束进程。
- 数据目录不在安装目录内，覆盖升级不会动你的案例、素材与候选池。
- 反方向（从 1.0.3 降级到 1.0.0）仍会提示，并且**降级后旧程序可能因数据库版本更高而无法启动**；如需降级，请先自行备份数据目录（`%APPDATA%\com.jiexu.interface`）。

## 已知问题

- 安装包未签名，首次运行可能出现 SmartScreen 提示。
- 仅提供 Windows x64；macOS 未验证。
- 降级路径只修正了版本号显示，不承诺旧版本能打开更高版本的数据库。
- 其余功能与已知限制同 v1.0.2。
