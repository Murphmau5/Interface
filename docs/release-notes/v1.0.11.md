# v1.0.11 — 快捷键与命令面板

**发布类型**：交互发布版（键盘通道补齐 + 设置页快捷键表）
**适用平台**：Windows 10 1803+ / Windows 11（x64）

## 版本亮点

1.0.10 之前，界面里所有动作都要用鼠标点。这一版把高频操作搬上键盘：一个 `Ctrl+K` 命令面板统管搜索、切类目、切视图、切主题、跳设置，另外四条直达键覆盖「找、建、导、退」。

### 1. 命令面板：一个入口统管全部动作

- `Ctrl+K` 打开，再按一次关闭；`Esc` 也能关。
- 五组共 **52 条**命令：操作 2、导航 9、类目 36、视图 2、主题 3。
- 关键信息：面板底部常驻「N 条可用」，随搜索结果实时变化，不会出现空面板不知道还剩几条。

### 2. 搜案例直接跳转

- 输入任意关键词，除命令过滤外还叠加最多 6 条案例搜索结果（走同一套 SQL 搜索 + 拼音列）。
- 选中案例回车：先清空当前筛选与类目、退出合集，再跳转并把该案例落进中栏与右侧详情，不会出现「跳过去还是旧列表」。

### 3. 切类目不用回左栏

- 36 个类目全部进面板，执行后等价于「打开对应内容域 + 选中该类目 + 聚焦列表」，左栏层级仍是两层，不会因为面板而推第三层。

### 4. 视图与主题一键切换

- 网格 / 表格：当前项标注「当前」，重复执行无副作用。
- 主题：跟随系统 / 深色 / 浅色，切换同时写入 `settings.themeMode`，重启后保持；`appearance.theme` 与 `themeMode` 各管一段，互不覆盖。

### 5. 四条直达键

- `Ctrl+F` 或 `/`：聚焦当前页搜索框（全选已有内容，直接输入即替换）；当前页没有搜索框时落到案例库再聚焦。
- `Ctrl+N`：新建案例。在内容域内就地展开；在其他页面先落到对应内容域，再展开表单并把焦点交给标题输入框。
- `Ctrl+E`：导出当前案例。只有详情已选中时才注册，未选中时按键不占用。
- `Esc`：层级返回。**语义与之前完全一致**——先清类目，再回一级导航；本轮没有趁机改它。

### 6. 与输入框共存

- 单键 `/` 在 input / textarea / select / contenteditable 内不抢键，正常输入。
- 带修饰键的组合（`Ctrl+K/F/N/E`）在输入框内仍然生效，符合「全局命令优先」的桌面习惯。
- 命令面板打开期间，除面板自身处理的键以外全部吞掉，不会穿透到下面的列表或搜索框。
- 输入法组合态（`isComposing`）断开处理，拼音选词时按回车不会误执行命令。

### 7. 设置页快捷键表

- 新增「快捷键」分区，10 条只读表：按键 / 动作 / 生效范围 / 说明。
- 表与实现同源（`src/lib/shortcuts.ts`），不是另写一份文案，后续改键不会漂移。
- 支持设置搜索命中「快捷键」「面板」「导出」等关键词。

### 8. 顺手修掉的两个真问题

- **跨路由新建不展开**：路由切换会复用同一组件实例，局部 `creating` 状态初值不重算，导致 `Ctrl+N` 从案例库跳到风格页后只换了页面没有表单。改为到达后按待办请求显式置位并聚焦标题。
- **面板里出现点了没反应的导出项**：面板按「动作是否已登记」决定是否展示「导出当前案例」，避免在没有选中案例时给出死条目。

### 9. 回归通道

- 新增 `scripts/ui-shot/palette-check.mjs`：无头 Edge + CDP 跑 12 项断言（面板开关、过滤并执行、吞键、`/` 不抢键、跨路由新建、主题切换、快捷键表行数与可交互控件数、`Esc` 层级语义不变）。
- 12/12 通过；`tsc --noEmit`、`eslint .`、`vite build`、许可证白名单全过。

### 10. 真窗口验收一次跑完的准备

- 真窗口专属项（标题栏拖动 / 双击最大化 / 边缘吸附 / 原生拖拽导入 / 安装器单屏交互 / 首启内置导入 / `Ctrl+E` 落盘）本轮仍**未实测**，但清单与一键脚本已随本版交付：开一次窗即可按序跑完并产出报告，见 `docs/acceptance/real-window-checklist.md`。

## 需要 Key 才能用

本版没有新增需要 Key 的功能。AI 分析与联网搜索仍需在设置里配置 Key。

## 不配 Key / 没有服务器也能用

- 78 条内置案例的浏览、搜索、四维筛选、网格 / 表格切换
- 全部快捷键与命令面板（面板内的案例搜索走本地库，不联网）
- 五类预览渲染与参数调节、标签 / 收藏 / 合集 / 最近使用
- Markdown / JSON 导出、素材导入与 HTML 清洗预览
- 内容包本地导入 / 在线安装 / 卸载

- 命令面板类目条目数随内容包目录增长，不硬编码为 36。
