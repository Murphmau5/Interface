# v1.0.14 — 复制给 AI 与搜索双作用域

**发布类型**：自用效率发布版（AI 出口 + 主搜索框双作用域接线）
**适用平台**：Windows 10 1803+ / Windows 11（x64）

## 版本亮点

1.0.13 让新装用户知道这是什么软件，这一版解决两件天天要做的事：把案例递给 AI，以及在正确的作用域里找东西。

### 1. 详情页两个复制动作

| 动作 | 输出什么 |
|---|---|
| 复制提示词 | 只取提示词正文，用于直接贴进 AI 对话 |
| 复制为 Markdown | 标题 / 内容域 / 类目 / 置信度 / 参数表 / 提示词，整段结构 |

复制后在原位常驻一行反馈：`已复制提示词 · 92 字 · 02:02:15`。它不会几秒后自己消失——这类提示一闪而过，反而让人不确定到底复制了什么。改参数时反馈清空，避免把旧文案当成新内容。

输出的文本是干净的：不带界面角标、条数计数、`Ctrl` 提示或内部 ID。

### 2. 多选与批量

- `Ctrl` / `⌘` 点击逐条切换。
- 按住空白处拖出矩形即框选（位移超过 4px 才进入框选，不影响单击选中）。
- 表格视图的行同样支持 `Ctrl` 点击。
- 「全选当前结果 · N」按当前搜索与筛选生效，再点变「取消全选」。

选中后列表顶部出现粘性条：`已选 N 条`，右侧是「复制 Markdown」「导出文件」「清空」。复制完的状态行给出条数与字数：

```
已复制 20 条 · 5,967 字 · 0.1ms · 02:02:18
```

「导出文件」一次写两个文件：Markdown（条目间 `---` 分隔）与 JSON（保留 `schema: interface.cases/v1` 与导出时间），文件名带选中条数。

选择状态绑定当时的查询：切类目、改筛选、换搜索词后旧选择自动失效，不会批量复制到已经看不见的条目。

### 3. 主搜索框真正接上双作用域

此前的实现有个缺口：搜索框里按 `Ctrl+Enter` 只把作用域切到「联网」，既不检索也不出结果，还得再到发现页手动操作一遍。这一版把按键接到实际检索上。

| 操作 | 行为 |
|---|---|
| 普通输入 | 只搜本地库，不发任何联网请求 |
| `Ctrl+Enter`（已配置 Key） | 发起联网检索，结果进「网络候选 · 未审核」单独一块 |
| `Ctrl+Enter`（未配置 Key） | 降级：提示「已降级为粘贴网址抓取」，切到联网面板并把焦点落到网址输入框，不发起检索请求 |
| 本地零结果 | 列表底部出现「本地没有找到，要不要联网找找」 |

零结果提示的按钮随配置变化：有 Key 是 `Ctrl+Enter 联网`，没 Key 是「粘贴网址抓取」。

### 4. 联网结果不进库列表

「网络候选 · 未审核」是独立一块，置于列表之上：

- 不进库列表，本地列表的条数、排序、选中与「已选 N 条」都不受影响。
- 每行标注「待审核 / 已存在 / 失败」，标题取候选标题，取不到时退回网址。
- 要入库仍然只能显式审核：点「去候选池审核」进发现页，没有免审开关。

### 5. 回归覆盖

- `scripts/ui-shot/ai-export-check.mjs`：18 项断言，覆盖单条两个动作、反馈常驻、Markdown 结构与干净度、`Ctrl` 点选、框选、全选 20 条、批量复制、批量导出、切换类目后选择不残留。
- `scripts/ui-shot/search-scope-check.mjs`：10 项断言，两套配置（无 Key / 有 Key）各跑一遍：默认只搜本地、本地命中不联网、零结果提示、降级按钮文案、`Ctrl+Enter` 出候选块、库列表零污染、网关只被调用一次。
- 静态门：`tsc --noEmit`、`eslint .`、`vite build`、许可证白名单全过。

无头环境下实测：单条提示词 77–168 字，单条 Markdown 234–380 字，批量 20 条合计 5,967 字，从按下 `Ctrl+Enter` 到候选块出现约 111–123ms（含 100ms 轮询间隔）。

### 6. 真窗口验收仍未复测

标题栏拖动、双击最大化 / 还原、边缘吸附、原生拖拽导入、安装器单屏交互这些只在真窗口里成立的项，本轮仍未实测；清单与一键脚本随版本保留在 `docs/acceptance/real-window-checklist.md`。

## 需要 Key 才能用

联网检索需要一个搜索服务 Key（设置 → 搜索服务，Bing / Tavily / Brave）。不需要 Key 的是：粘贴网址抓取、本地搜索、AI 出口的全部复制与导出。

## 不配 Key / 没有服务器也能用

- 本地搜索、四维筛选、网格 / 表格切换、全选与批量
- 单条复制提示词 / 复制为 Markdown、批量复制、批量导出 Markdown + JSON
- 粘贴网址抓取候选（公开 http/https 地址）
- 78 条内置案例的浏览与预览调参、标签 / 收藏 / 合集 / 最近使用
- 全部快捷键与命令面板、内容包导入 / 更新检查

## 已知限制

- 批量复制的耗时数字是无头环境下的 JS 侧测量；真机含原生剪贴板写入，数字会略高。
- 候选块一次最多展示 8 条，超出部分需去发现页查看完整队列。
- 框选只在网格视图可用；表格视图用 `Ctrl` 点击或「全选当前结果」。
