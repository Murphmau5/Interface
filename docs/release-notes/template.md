# 发版说明模板

> 复制本文件为 `vX.Y.Z.md`，按实际内容填写。发布前删除本行与未使用的占位。

## 发布口径（先看这一段）

- **测试构建**：版本号沿用 `1.0.x` 递增（如 1.0.16）。只在本机构建，**不上传 GitHub、不建 Release、不加附件、不推 tag**；发版说明可以留档在 `docs/release-notes/`，但不得对外链接下载。
- **正式发布**：只有在明确说「开始上传」时才执行；正式版版本号为 `1.1.0`。届时才创建 Release、上传安装包并推送 tag。
- **GitHub 远端**：只保留 `v1.0.0` 基线；下载链接只指向 v1.0.0。详见 `DECISIONS.md` D-034。
