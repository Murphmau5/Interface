# v1.0.0 — 初始框架预览版

**发布日期**：2026-11-08
**发布类型**：初始框架预览版
**适用平台**：Windows 10 1803+ / Windows 11（x64）
**状态**：已发布（GitHub Releases，附件为 NSIS 安装包，未签名）

## 摘要

界序 INTERFACE 的首次公开版本，定位为**初始框架预览版**：用于验证三栏工作台、双主题、左栏导航栈、底部类型条带与预览框架。AI 分析与自动发现不在本版承诺范围内。

## Added

- 三栏工作台外壳：TopBar / LeftNav / 列表区 / 详情区。
- 左栏导航栈（域 → 类目，≤ 2 层，240ms 推入，三路返回）。
- 底部类型条带：风格 / 控件 / 主题 / 动效 / 反馈。
- 双主题 Token：跟随系统（默认）/ 深色 / 浅色。
- 本地案例库与网格 / 表格两种视图。
- 右侧预览窗与参数面板骨架。
- 卡片悬停 140ms 自动预览（共享预览层）。
- 中文优先界面与集中词条表。
- 本地中文搜索：trigram 子串 + 分词 + 拼音索引。
- MIT LICENSE、素材来源登记与第三方声明。

## Changed

- 产品名统一为「界序 INTERFACE」；`UI Motion Lab` 仅内部代号。
- 数据库访问采用 rusqlite（bundled）。
- AI 落库校验改为 Rust 侧硬门禁 + Zod 第二道。
- 素材存储改为内容寻址对象库 + `case_assets` 关联。

## Fixed

- 修复跨文档中的数据模型重复引用与设置键不一致问题。
- 修复预览双快照对无头渲染的隐式依赖（改为双实例优先、静态快照降级并标注）。

## Security

- BYOK：不内置密钥、不代理转发；密钥不写入数据库、日志或导出包。
- 预览运行于 sandbox iframe；不启用 `allow-same-origin`。
- 依赖许可白名单与构建期检查。

## Known Issues

- 首次发布为框架预览版，AI 分析与 AI 自动发现标记为「规划中」。
- 部分复杂动效案例以简化规格呈现，参数可能为 `estimated`。
- 安装包**未做代码签名**，首次运行可能触发 Windows SmartScreen；请核对 SHA-256 后选择「仍要运行」。
- 双实例主题快照在低配设备上可能降级为静态快照。
