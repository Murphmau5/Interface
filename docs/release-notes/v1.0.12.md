# v1.0.12 — 在线内容更新

**发布类型**：数据链路发布版（在线检查更新 + 影响面预览 + 结果摘要）
**适用平台**：Windows 10 1803+ / Windows 11（x64）

## 版本亮点

1.0.10 让安装包自带 78 条案例，1.0.11 补齐键盘通道。但内容包只能「导入」或「从地址安装」，装完之后想知道有没有新版本、更新会动到哪些条目，都没有入口。这一版把在线更新补成一条完整链路：先检查、再预览影响面、最后才写入。

### 1. 设置页新增「在线更新」

- 位置：设置 → 内容包 → 「在线更新」卡片。
- 一个「检查更新」按钮：下载 `content.feedUrl` 指向的内容包、校验签名、与已装版本比较。
- 只在点按钮时执行，**不做后台轮询**，不联网时不会有任何后台请求。

### 2. 三种检查结果，各有各的说法

| 情况 | 界面反馈 |
|---|---|
| 未配置在线地址 | 「尚未配置在线地址；本地导入和手动导入不受影响。」不报错 |
| 已是最新 | 「已是最新 vN（共 M 条）」 |
| 有新版本 | 「有新版本 vN（新增 x 条 / 移除 y 条）」+ 影响面 + 安装按钮 |

### 3. 更新前先看影响面

点开新版本后会写明本次会触碰多少条：

- 需要更新多少条；
- **你改过的 N 条会保留**；
- **你删过的 N 条不会被带回**。

不需要这次更新时点「稍后再说」，不会写入任何数据。

### 4. 更新后给五项摘要

安装完成后不再只提示「成功」，而是给出：**新增 / 更新 / 跳过 / 保留 / 移除** 各几条，能直接对上刚才预览的影响面。

### 5. 检查与安装分两步

- `content_package_check_update`：只读。下载、验签、算差异都在事务里完成，结束回滚，不写库、不改设置。
- `content_package_apply_update`：只有用户点「安装更新」才写入，合并规则与在线安装完全一致。

### 6. 网络失败分开说

不再把所有问题都叫「更新失败」，按错误码给不同的前缀：

| 错误码 | 提示 |
|---|---|
| `E_PKG_FEED_UNREACHABLE` | 地址不可达（超时 / 连接失败） |
| `E_PKG_FEED_INVALID` | 地址无效（协议、域名、重定向异常） |
| `E_PKG_FEED_HTTP` | 地址返回错误（非 2xx，附状态码） |
| `E_PKG_SIGNATURE` | 签名不通过 |
| `E_PKG_APP_TOO_OLD` | 版本过低（`minAppVersion` 高于当前应用） |
| `E_PKG_TOO_LARGE` | 包超限（超过 64 MB） |
| `E_PKG_FEED_NOT_CONFIGURED` | 未配置地址 |

网络类错误（不可达 / HTTP 错误 / 下载中断）标记为可重试。

### 7. 下载链路收紧

- 重定向最多 5 跳，**每一跳都重新校验 URL**，跳转到内网地址会被拦截。
- 体积按响应头与流式累计双重限流，64 MB 上限在下载过程中生效，不是下完再判断。

### 8. 地址草稿变化即清空旧结论

编辑在线地址输入框时，上一次的检查结果与提示立即清空，避免旧地址的结论挂在新地址下面。

### 9. 回归覆盖

- `e2e::content_package_update_check_and_apply`：正常升级（用户改过的保留、删过的不复生、清单内移除生效）、签名不符、`minAppVersion` 高于当前、feed 不可达、未配置地址五种情况。
- 本地假 HTTP 服务构造 manifest 与 zip，不依赖公网。
- `cargo test --lib`：70 条，68 通过 / 2 忽略（公网抓取、搜索基准延迟）。
- 静态门：`tsc --noEmit`、`eslint .`、`vite build`、许可证白名单全过。

### 10. 真窗口验收仍未复测

标题栏拖动、双击最大化 / 还原、边缘吸附、原生拖拽导入、安装器单屏交互这些只在真窗口里成立的项，本轮仍未实测；清单与一键脚本随版本保留在 `docs/acceptance/real-window-checklist.md`，等统一开窗时一次跑完。

## 需要 Key 才能用

本版没有新增需要 Key 的功能。AI 分析与联网搜索仍需在设置里配置 Key。

## 不配 Key / 没有服务器也能用

- 78 条内置案例的浏览、搜索、四维筛选、网格 / 表格切换
- 全部快捷键与命令面板
- 五类预览渲染与参数调节、标签 / 收藏 / 合集 / 最近使用
- Markdown / JSON 导出、素材导入与 HTML 清洗预览
- 内容包本地导入 / 在线安装 / 卸载
- 在线更新检查（需要配置 `content.feedUrl`；未配置时只提示，不影响其他功能）

## 验证范围

**已通过**：

- 静态门：`tsc --noEmit`、`eslint .`、`vite build`、许可证白名单。
- Rust：`cargo test --lib` 70 条（68 通过 / 2 忽略），含在线更新五种分支的端到端用例。
- 本地假服务器覆盖：正常升级、签名不符、版本过低、feed 不可达。

**未验证**：

- 真实公网 feed 地址未实测（仅用本地假服务器）。
- 真窗口交互（标题栏拖动、双击最大化 / 还原、边缘吸附）未复测。
- 原生拖拽图片导入未复测。
- 安装器单屏交互未复测。
- 仅 Windows x64；macOS 未验证。

## 已知限制

- 更新粒度是「整包」：不支持只下发某几条的增量包。
- 未配置 `content.feedUrl` 时没有默认地址，需要自己填写可访问的 zip 直链。
- 触觉反馈条目仍暂缺，等有可用触觉通道再补。
