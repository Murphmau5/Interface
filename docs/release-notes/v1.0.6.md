# v1.0.6 — 联网抓取链路

**发布类型**：功能版
**适用平台**：Windows 10 1803+ / Windows 11（x64）

## 版本亮点：联网采集链路

这一版把「从网上收素材」这条路打通了：粘一个公开网址，正文就进候选池等你审。全程不自动入库、不自动执行 HTML。

- **单 URL 直接抓取**：粘贴公开 http/https 网址，应用抓取正文写入「候选池」待审核。
- **URL 守卫**：只允许 http/https；拒绝带用户名密码、本机 / 内网 / 链路本地 / 保留地址与内部域名；重定向逐跳校验，最多 5 跳；单页响应上限 2 MB；只接受 `text/html`、`application/xhtml+xml`、`text/plain`。
- **正文提取**：剥离 script / style / noscript / 注释 / SVG，取 title、meta description 与正文。
- **两层去重**：同一规范化 URL 在非 rejected 候选中存在则不重复创建；内容近似也判重（字符二元组 Jaccard ≥ 0.85，且两边文本均 ≥ 120 字）。
- **搜索采集**：支持 Tavily / Brave / Bing / custom 四种搜索服务配置，命中后逐条抓取入候选池。
- **失败不静默**：逐条返回 `{ url, outcome, code, message }`，批量汇总 created / duplicates / failed。
- **新增错误域**：`AppError::Fetch`，错误码 `E_URL_INVALID`、`E_URL_SCHEME`、`E_URL_BLOCKED`、`E_URL_REDIRECT`、`E_FETCH_TIMEOUT`、`E_NETWORK`、`E_HTTP_STATUS`、`E_CONTENT_TYPE`、`E_TOO_LARGE`、`E_EMPTY_CONTENT`、`E_SEARCH_UNAVAILABLE`、`E_SEARCH_PARSE`。

## 需要 Key 才能用

以下能力必须先在「设置」里填入你自己的 Key，不配则入口可用但请求不会发出：

- **AI 工作台分析**（OpenAI 兼容模型服务）
- **搜索采集**：Tavily / Brave / Bing / custom 四种搜索服务

Key 保存在 Windows 凭据管理器，不内置、不代理转发。

## 不配 Key 也能用

以下能力完全本地，不需要任何 Key：

- 粘贴网址抓取（单 URL 抓取入候选池）
- 手动登记候选
- 候选审核入库（通过 / 拒绝 / 编辑后入库）
- 案例库浏览 / 筛选 / 搜索
- HTML 导入与预览

## 验证范围

**已通过**：
- 本地假 OpenAI 兼容服务器端到端跑通「保存 Key（Windows 凭据管理器）→ 测试连接 → 工作台分析 → 候选池 → 人工审核入库」，并验证模型返回 `verified` 时被降级为 `estimated`。
- 本地假 HTML 服务器端到端跑通「首次 created → 二次 duplicate」。
- 真实公网抓取：对 `https://example.com` 走生产守卫与提取链路抓取成功（状态 200、标题与正文提取正常、无重定向）。

**未验证**：真实第三方搜索 Provider（Tavily / Brave / Bing）与真实第三方大模型服务的端到端调用**未验证**。原因是本地只有假服务器测试环境，没有真实 Key，未做过一次真实的第三方请求。请不要把本版视为「已联调通过真实服务」。

**未做 GUI 自动化验证**：上述端到端均在 Rust 层用真实命令路径（同一套 `create_case` / `approve_candidate` / `insert_candidate` / `fetch_page`）执行，未启动窗口做点击级自动化。

## 升级说明

- 覆盖安装保留数据：**是**。数据目录不在安装目录内，案例、素材与候选池不受影响。
- 是否需要备份：建议备份 `%APPDATA%\com.jiexu.interface`。
- 数据库迁移：有。直接双击新包即可覆盖升级，不需要先卸载旧版本。
- 从更高版本降级仍会提示，且旧程序可能打不开更高版本的数据库。

## 已知限制

- 抓到的 HTML 一律以 `html.state = "unclean"`、`needsCleaning = true` 入库，只存 ≤ 16 KB 摘要，**不执行、不渲染**；要看得先走导入 HTML 的清洗流程。
- 内网 / 本机 / 链路本地 / 保留地址与内部域名会被直接拒绝，本地自建站点无法抓取。
- 搜索采集必须先在设置里配置搜索服务与 Key，未配置时只能用「粘贴网址抓取」。
- 真实第三方搜索 Provider 与真实模型服务端到端未验证（无真实 Key）。
- 安装包未签名，首次运行可能出现 SmartScreen 提示。
- 仅提供 Windows x64；macOS 未验证。
