# v1.0.9 — 预览舞台撑满与明度阶梯

**发布类型**：缺陷修复版（视觉硬伤 + 配色分级 + 验证通道）
**适用平台**：Windows 10 1803+ / Windows 11（x64）

## 版本亮点

1.0.8 把三栏改成了仪器台，但截图复核发现两处真问题：预览画布几乎空白、深色三栏明度差不足。这一版只修这两条硬伤和随之暴露的浅色强调问题，不引入新功能，数据模型与 IPC 契约未改。

### 1. 预览舞台按内容自然高度排布，导致画布近乎空白（硬伤）

- **问题**：预览舞台的高度由内容本身决定，而不是由可用空间决定。400px 高的画布里场景只占一条，四周留白把可用面积吃掉，五种预览都看不出风格到底是什么。
- **修复**：五种预览类型（风格 / 动效 / 反馈 / 组件 / 主题）统一改为「演示板」结构——顶部读数条、角标、底部参数摘要，场景按舞台 9% 的演示边距撑满可用高度并水平居中。
- **实测**（真实库，舞台 754×232）：场景 618×190，**高度占比 82.0%，水平中心偏差 0.0%，四边溢出 0**，五种类型全部达标。

### 2. 深色三栏明度差不足

- **问题**：左栏、中栏、画布几乎糊成一块黑，边界全靠 1px 描边区分。
- **修复**：深色改为四级明度阶梯——画布 `#010203` → 详情 `#05080B` → 中栏 `#0C1319` → 左栏 / 卡片 `#1A2530`，标题栏跟随左栏、控件底 `#121A22`。
- **实测**：渲染主色 L\* 约 1 / 4.9 / 14.6，左栏对中栏差约 10 个 L\*，肉眼可分。

### 3. 浅色强调与标题截断

- **强调色**：accent 提到 `#0A6F7D`，`accent-soft` / `accent-line` 加饱和；四个状态色同步加深。
- **状态点**：`.confidence-dot` 由 5px 改 7px 并加同色光晕——已验证用 accent、推测用 warning、用户定义用 info，浅色下不再「看不见」。
- **主行动着色**：详情「保存 / 添加 / 加入」与列表「新建」此前是白底灰字，改为主行动样式；全局主按钮同一套底色。
- **标题**：详情标题原本没有截断规则，长标题换行会撑高头部；改为 2 行截断 + 悬停显示完整标题，头部本身不裁剪。

## 新增：真实库只读复核通道

- `scripts/ui-shot/fixtures.mjs` 新增 `loadRealFixtures()`：用 Node 24 内置 `node:sqlite` **只读**打开 `%APPDATA%\com.jiexu.interface\app.db`，直接读 `cases` 表，不写库、不经过夹具。
- `shot.mjs` 新增 `--fixtures real|demo`，截图、压测、舞台审计都可以跑真实数据。
- 动机：夹具的 14 条案例掩盖了「空场景」这类问题；真实库当前只有 5 条案例、0 合集、0 标签、payload 只有最小字段，比夹具更苛刻，画布填充与三栏阶梯在这套数据上同样成立。

## 需要 Key 才能用

本版没有新增需要 Key 的功能。既有的 AI 分析与联网搜索仍需在设置里配置 Key，未配置时保持禁用并给出可读提示。

## 不配 Key / 没有服务器也能用

- 案例库浏览、搜索、四维筛选、网格 / 表格切换
- 五类预览渲染与参数调节（含暂停 / 重播 / 循环 / 速度）
- 标签、收藏、合集、最近使用
- Markdown / JSON 导出、素材导入与 HTML 清洗预览
- 内容包本地导入与卸载
