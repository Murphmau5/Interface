# v1.0.7 — 内容包与在线更新

**发布类型**：功能版
**适用平台**：Windows 10 1803+ / Windows 11（x64）

## 版本亮点：内容包

这一版把「素材库从网上更新」做成了可安装的内容包：一个签名 zip，本地导入就能装；在线地址可以以后再配，不配也不影响本地导入。更新按版本合并，用户改过的条目不会被覆盖，删过的条目不会被更新复活，卸载也不会伤到自建数据。

- **内容包格式**：签名 zip，根目录 `manifest.json` + `signature.txt` + `content/...`；manifest 记录格式版本、包 id / 名称 / 版本、`minAppVersion`、条目清单、逐文件 SHA-256，以及可供增量更新使用的 `removedItems`。
- **签名校验**：manifest 原始字节用 Ed25519 签名；应用内置发布公钥，也可在设置项 `content.trustedKeys` 追加自建公钥。签名不符、密钥不受信任都整包拒绝。
- **本地导入独立可用**：把 `.zip` 拖进窗口，或填写完整路径点「导入」即可；不依赖任何在线服务、Key 或账号。
- **在线地址可配置**：设置项 `content.feedUrl`（设置页「内容包 → 在线地址」）；留空时在线安装返回可读提示，本地导入照常。下载只接受 http/https，重定向逐跳校验，仍走同一套 manifest / 哈希 / 签名校验。
- **整包拒绝**：manifest 不合法、缺少登记文件、文件哈希不符、包含未登记文件、条目文件不是 JSON 对象、HTML 清洗被拒，任一失败都不写入数据库，并给出具体文件或条目 id。
- **路径与可执行文件守卫**：zip 条目名拒绝 `..`、绝对路径、盘符、反斜杠与控制字符；拒绝 `.exe / .dll / .bat / .cmd / .ps1 / .js / .msi / .jar` 等可执行扩展名。
- **包内 HTML 同一套清洗器**：条目可通过 `htmlPath` 携带 HTML，读入后走与素材导入相同的白名单清洗，原始 HTML 永不入库，清洗结果嵌入 `payload.html`。
- **合并策略**：同 id 条目按版本比较；用户改过（标题 / 摘要 / 载荷 / 类型 / 平台 / 置信度任一变化）不覆盖；用户删除过的不复活；只有 manifest 显式声明的 `removedItems` 才会移除条目；拒绝降级安装；同版本不同内容拒绝覆盖。
- **卸载干净**：只移除该包带来且未被改动的条目；用户改过或收藏过的条目保留并解除内容包绑定；用户自建案例与其他内容包不受影响。
- **容量上限**：包体 64 MB、解压总量 256 MB、单文件 8 MB、条目 2000、zip 条目 5000，并做压缩比异常拦截（防压缩炸弹）。
- **新增错误域**：`AppError::ContentPackage`，错误码 `E_PKG_INVALID_ZIP`、`E_PKG_MANIFEST`、`E_PKG_SIGNATURE`、`E_PKG_MISSING`、`E_PKG_HASH`、`E_PKG_PATH`、`E_PKG_EXECUTABLE`、`E_PKG_TOO_LARGE`、`E_PKG_VERSION`、`E_PKG_ITEM`、`E_PKG_DOWNLOAD`。
- **设置页新增「内容包」**：本地拖拽 / 路径导入、在线地址保存与在线安装、已安装列表与两步确认卸载，错误直接显示错误码与可读原因。

## 需要 Key 才能用

无。本版内容包功能不依赖任何 Key、账号或第三方服务。

## 不配 Key / 没有服务器也能用

- 本地导入签名内容包（拖拽或路径）
- 已安装内容包列表与卸载
- 包内 HTML 清洗与预览数据写入
- 案例库、候选池、标签、收藏等既有本地能力

**在线安装**需要你自备一个可访问的内容包地址；应用不内置分发服务器。不配置地址时，本地导入是完整可用的安装路径。

## 验证范围

**已通过（本地测试，64 项 Rust 测试全绿）**：

- 正常包：导入成功、ID 与版本正确、包内 HTML 经清洗后 `script` 被移除、标签写入、已安装列表可见。
- 缺文件包：manifest 登记但 zip 未提供 → `E_PKG_MISSING`。
- 哈希不符包：文件内容与 manifest 哈希不一致 → `E_PKG_HASH`。
- 篡改签名：使用不受信任密钥签名 → `E_PKG_SIGNATURE`。
- 恶意路径 `../`：包级拒绝 → `E_PKG_PATH`。
- 可执行文件：`.exe` 条目 → `E_PKG_EXECUTABLE`。
- 大包：600 条合法包导入成功（报告条目截断、统计完整）；2001 条超过条目上限 → `E_PKG_TOO_LARGE`。
- 合并：版本升级覆盖未改条目；用户改名后升级跳过；用户删除后升级不复活；降级拒绝。
- 增量：`removedItems` 移除未改条目，收藏条目保留并解绑。
- 卸载：未改条目删除；改过、收藏条目保留并解除绑定；用户自建案例保留；内容包记录清空。
- 端到端：本地写出签名包 → 读回导入 → 本地假 HTTP 服务器提供增量包 → 在线下载并合并 → 卸载，全程走真实数据库与真实文件。

**未验证**：

- 没有真实公网内容包分发服务器，在线安装只在本地假服务器上验证过；重定向逐跳守卫复用 1.0.6 的 URL 守卫，但未用真实 CDN 跳转演练。
- 内置签名公钥为开发签名密钥，私钥保存在本地 `.agent/keys`，未做发布级密钥管理；设置项追加公钥的路径有单元级覆盖，未做多发布者信任链演练。
- 安装包未签名，首次运行仍可能出现 SmartScreen 提示。
