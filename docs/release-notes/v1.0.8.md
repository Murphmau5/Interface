# v1.0.8 — 主界面仪器台化

**发布类型**：界面重构版
**适用平台**：Windows 10 1803+ / Windows 11（x64）

## 版本亮点：三栏主界面重做

1.0.7 之前只有设置页和标题栏是 Chrome 那套结构，列表区与详情区仍偏后台管理：控件堆叠、层级靠边框硬切、参数挤成一片滑块。这一版把主界面三栏按同一套仪器台语言重做——胶囊选中态、发丝线分区、等宽读数、克制的表面层次。数据模型、IPC 契约、搜索与筛选语义都没有改。

### 左栏

- **胶囊选中态统一**：与设置页同一套 `rounded-pill + accent-soft + 内描边`，去掉左侧竖条；图标在选中时转 accent。
- **计数徽标**：内容域、二级面板类目、合集都用等宽数字徽标，选中时换 surface 底并描边；读数与标题同基线。
- **分组层次**：内容域 / 工具位之间用发丝线分组；组标题右侧带「N 条」总读数；合集区独立成组。
- **底部读数瓦片**：收藏 / 最近使用改为两枚并排 quick-tile（图标 + 名称 + 大号计数），选中态复用胶囊规则。
- **底栏**：`本地库 · SQLite` 与版本号 mono 读数，顶部发丝线与列表分开。
- **二级面板**：返回行胶囊化，域标题旁带总数徽标，不可用项用弱化徽标替代整行灰字。

### 中栏列表

- **头部降噪**：eyebrow（LIBRARY / 全部）+ 标题 + 总数徽标一行；描述限一行；类目面包屑胶囊化。
- **工具栏**：搜索与「本地 / 联网」「网格 / 表格」分开层级；「＋ 新建」只在内容域出现，点开是内联 composer，不再常驻大表单。
- **筛选**：四维筛选改为三列网格（类型 / 平台 / 置信度 / 组件层 / 排序），重置按需出现；Select 宽度真正作用在外层容器上，不再只缩 `<select>`。
- **卡片**：按容器宽度 1 / 2 / 3 列自适应，按「行」虚拟滚动；缩略图比例随列数变化；标题两行、元信息一行（类型 · 平台 · 置信度点）；收藏按钮固定在右上角。
- **悬停**：保留 140ms 共享预览层，悬停后原地换成实时预览，不新开窗口。
- **表格**：`table-fixed` 固定列宽，类型 / 平台 / 置信度按中文实测放宽，横向滚动条消失；表头与单元格左边界偏差为 0；选中行用 accent-soft，不再整行变蓝。

### 右栏详情

- **分节**：预览与参数 / 标签 / 合集 / 素材 / 导出 / 属性 / 更多操作各自成节，节标题为 eyebrow + 发丝线 + 右侧读数，节间距统一 20px。
- **头部**：标题就地重命名（铅笔进入，保存 / 取消），元信息 chips，收藏改为与铅笔同尺寸的图标钮。
- **舞台**：工具条移到预览上方（暂停 / 重播 / 循环 / 速度），底部 mono 状态行（类型 · 场景 · 参数摘要）。
- **参数面板**：按外观 / 播放 / 运动分组，每行「标签 / 控件 / 读数」三列，滑块不再挤成一片；数值列等宽对齐。
- **素材**：默认折叠，标题带计数，展开后才出现拖拽导入、清洗徽标与隔离预览入口。
- **危险操作**：折叠在底部，删除两步确认可取消。

### 全局

- **Token 化**：新增 `--panel-highlight`、`--control-bg`、`--control-line`、`--rail-active-ring` 等语义 token；新规则只引用 token，圆角只用 `--radius-*`，没有写死色值。
- **深浅两套**：浅色下 accent-soft / accent-line 重新配平，深色下卡片描边与舞台网格单独调过，两套都逐个界面看过。
- **修掉的显示 bug**：详情节标题出现双发丝线（`::after` 与显式 span 叠加）、表格平台 / 置信度列被挤到相邻列、新建 composer 与「没有匹配」空态同时出现、详情收藏按钮比铅笔大一截。
- **密度决策**：不新增「紧凑 / 舒适」自适应开关。理由是网格与表格已经承担了密度选择；最小窗口 1000×680 下再做可变密度会多出一整套裁切与双主题 QA 面，固定光学节奏更接近仪器台。记录保存在 `.agent/spec/phase-5/spec.md`。
- **无窗口验证通道**：新增 `scripts/ui-shot`（无头 Edge + CDP），可在不弹出应用窗口的情况下完成主界面截图与随机操作压测；需要真窗口的项目（标题栏拖动、原生拖拽导入）攒批处理。

## 需要 Key 才能用

本版没有新增需要 Key 的功能。既有的 AI 分析与联网搜索仍需在设置里配置 Key，未配置时保持禁用并给出可读提示。

## 不配 Key / 没有服务器也能用

- 案例库浏览、搜索、四维筛选、网格 / 表格切换
- 五类预览渲染与参数调节（含暂停 / 重播 / 循环 / 速度）
- 标签、收藏、合集、最近使用
- Markdown / JSON 导出、素材导入与 HTML 清洗预览
- 内容包本地导入与卸载（1.0.7 能力，本版未改动）
