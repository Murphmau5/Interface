# v1.0.1 — 预览体系与真实类目版

**发布日期**：2026-11-09
**发布类型**：功能版
**适用平台**：Windows 10 1803+ / Windows 11（x64）
**状态**：已发布（GitHub Releases，附件为 NSIS 安装包，未签名）

## 摘要

本版把预览从「三条固定演示」改成「按类型拆分的可调渲染器」，把左栏里写死的占位分组换成 SQLite 中真实落库的 36 条类目，并打通「新建 → 调参 → 实时预览 → 自动存库 → 导出 Markdown」的完整闭环。窗口默认尺寸同步改为三栏布局的最小可用尺寸。

## Added

- 预览按 `kind` 拆成五个独立渲染器（动效 / 反馈 / 组件 / 主题 / 风格），全部自绘，不加载任何外部素材、截图或录屏；打开任意案例都能看到与其类型匹配的场景，不再共用一套通用演示。
- 动效渲染器支持时长、延迟、阶梯间隔、位移、缩放、透明度、模糊、缓动八个参数：改哪一项，入场的节奏、起点与清晰度立刻跟着变。
- 反馈渲染器按「触发 → 停留 → 消退」三段参数驱动，三段时长独立可调，状态色随语气切换。
- 组件渲染器给的是真实可交互控件（开关、按钮、输入框），可以直接点、可以输入；关闭交互时改用 WAAPI 演示按压与聚焦。
- 主题渲染器用深色 / 浅色两层交叉淡入，完整周期由淡入时长与保持时长换算，调参即可看出切换节奏差异。
- 风格渲染器支持平面 / 新拟态 / 玻璃三种处理，圆角与深度是即时生效的数值，不是三张固定图。
- 类目落库 36 条（风格 8 / 动效 6 / 反馈 9 / 组件 8 / 主题 5），左栏计数改为 SQL 实时统计，不再是前端写死的 0。
- 左栏二级面板接入真实数据，带加载态、空态、失败重试与「域 › 类目」面包屑。
- 案例完整闭环：新建（可指定类目）→ 拖参数 → 实时预览 → 自动存库 → 导出 Markdown（元信息表 + 参数表 + 提示词 + 预览代码块）。

## Changed

- 参数面板与预览双向实时绑定，去掉「应用」按钮：拖动滑块或直接输入数值，画面当帧重播。
- 保存改为 600ms 防抖自动写入，切换案例或关闭详情时补写未落库的改动；面板上可见「未经改动 / 保存中… / 已保存 hh:mm:ss / 保存失败」。
- 左栏二级面板的空分组不再渲染，`Esc` 语义改为「先清类目，再按一次返回域」，三路返回（`Esc` / 返回按钮 / 面包屑）保持一致，240ms 栏宽位移未变。
- 窗口默认尺寸改为最小可用尺寸，并设定最小尺寸约束：`width = minWidth = 1000`、`height = minHeight = 680`（逻辑像素），启动即最小宽度，不再是 1320×840 的大窗；`resizable` 仍为 `true`，但拖不到比最小尺寸更小。
  - 取值依据：左栏 228（默认宽度）+ 分隔条 8 + 中栏 384（默认宽度）+ 分隔条 8 + 详情区最小可用 360 = 988，向上取整留 12px 余量得 1000；Tauri 的 `width/height` 是窗口内尺寸，不含系统边框，因此不额外加边框宽度。
  - 125% 缩放下实测：逻辑内尺寸 1000×680，物理 1250×850；左栏 228 / 中栏 384 / 详情 372，页面 `scrollWidth = innerWidth`，无横向滚动条，三栏完整、预览区可用。
- 构建管线改为隐藏窗口执行 + 日志判定，构建过程中不再反复弹出控制台窗口。

## Performance

- 列表改为固定行高虚拟滚动：405 条案例时实际只渲染十余张卡片，滚动高度仍按真实总高度计算。
- 缩略图缓存从「按张数」改为 200MB 字节预算 LRU：缓存占用有硬上限，长列表滚动不会无限堆积位图。
- 切换 100 次案例无持有型泄漏：DOM 节点数恒定 394、`document.getAnimations()` 恒定 10、`.preview-stage` 恒定 1；WebView2 内存在前 10 次一次性分配后进入 429–436MB 波动区间，不再单调增长。

## Known Issues

- 首屏 FCP 由 260ms 变为 328ms（+68ms），来自新增的五个渲染器与参数面板代码体量；仍在 350ms 预算内。
- 安装包**未做代码签名**，首次运行可能触发 Windows SmartScreen；请核对 SHA-256 后选择「仍要运行」。
- 导出成功后只显示文件路径文本，暂未提供「打开所在文件夹」按钮。
- 悬停微预览在滚动时销毁容器，但动画本身仍在运行；低配设备开启「减少动效」可降低占用。
- 重新打包前必须先关闭正在运行的 exe，否则 bundler 重命名二进制会报「拒绝访问」。
- 仅提供 Windows x64；macOS 未验证。
