# v1.0.15 — 参数证据链与并排对比

**发布类型**：可信度治理发布版（参数证据链 + 并排对比），附全量性能回归
**适用平台**：Windows 10 1803+ / Windows 11（x64）

## 版本亮点

1.0.14 把案例递给了 AI，这一版先解决「递过去的东西能不能信」。参数核实报告跑了 78 条：0 条能整条升 `verified`，9 行拿得到官方原文，26 行查不到。所以这一版不做「整体改成 M3 值」那种一刀切，而是给每个参数补上可核对的出处，并把出处摆到界面上。

同时把 1.0.14 里做了一半的并排对比补齐：两条案例左右同屏、同帧播放，参数差异逐行标注。

### 1. 参数级 `verified` 现在需要出处

`specRef` 的结构是 `{ platform, version, component, url, quote }`。规则写死在两侧：

- 五个字段齐全、`url` 是 `https`、`quote` 里能找到与数值一一对应的数字（或 cubic-bezier 的四个数值），才允许参数级 `verified`。
- 没有 `specRef` 的参数，最高只能 `estimated`。
- Rust 入库（`cases_create` / payload 更新）与内容包导入都走同一套归一化；前端读取时再校验一次，改过的老数据也降级。

这条不是装饰：`verified` 之前是可以手写的字符串，现在是一条要过机械校验的断言。

### 2. 点开就能看到证据

参数行上有一个来源标记：

| 点开的状态 | 显示内容 |
|---|---|
| 有 `specRef` | 平台与版本、组件名、官方原文引句、可点开的「打开官方文档」 |
| 无 `specRef` | 「无官方原文，来源为推测」 |

链接只走 https，命令层做了长度与字符检查；外链用系统浏览器打开，不在应用内开窗口。

### 3. 条目标明口径

平台类条目绑定到具体版本，避免「M3 是什么版本」的含糊：

- Material 3 Expressive 2025+
- Fluent 2 global tokens
- Apple HIG 2025
- HarmonyOS Design 2024+

33 个通用控件标注「非平台绑定」，**数值一个都没改**——那是设计选择，不是错误。

### 4. `style.material3` 的缓动改对了

原本是 M2 的 `cubic-bezier(0.4, 0, 0.2, 1)`，改为 M3 Standard `cubic-bezier(0.2, 0, 0, 1)`，并附官方原文。

### 5. 补 `hitTarget`

对需要外扩热区的 8 个控件补 `hitTarget: 24`，逐字引 WCAG 2.2 SC 2.5.8 的 24×24 CSS px，另附三平台参考值：Material 48dp、HIG 44pt、鸿蒙 48vp / 40vp，各自带 `specRef`。热区用透明 `::before` 外扩，不动控件视觉尺寸。

### 6. 并排对比

多选两条后进入对比视图：

- 左右两套真实预览渲染器同屏，`同时播放 / 同时暂停 / 同时重播`，也可只重播一侧。
- 只高亮值不同的字段，相同项默认折叠，可展开。
- 置信度不同时给出提示；一侧 `verified` 一侧 `estimated` 时明确写出「不要把两者当成同等可信」。
- 两侧内容域不同时只列同名字段，不硬凑。
- `Esc` 只退出对比，不再连带清类目或退回一级导航。

### 7. 内存与性能

用真实库 83 条做了全量回归，深浅两套各一轮：

- 冷启动：JS 堆 3.90 MB、WebView2 整树 415 MB、渲染进程 109 MB、FCP 396 ms、DOM 活节点 1035。
- 切换案例 100 次：DOM 在 2149–2239 之间按条目结构循环，不累积。
- 进入退出对比 50 次：对比内 2481 个节点 / 5 个动画对象 / 3 个预览舞台，退出后回到 2271 / 3 / 1，50 次全部回落，无残留表面。
- 命令面板 100 次：打开态恒为 2807 个节点，关闭后文档内活节点精确回到基线。
- 类目推入返回 50 次：2866 恒定。

与 1.0.5 相比：整树低 33 MB、渲染进程低 44 MB、JS 堆低一个量级（19.02 → 3.90 MB）。
对比打开时底层详情预览暂停、悬停微预览收起，这是本版额外的内存缓解。

## 已知限制

- 26 行参数查不到官方原文，按规则停在 `estimated`；后续补到出处才会升。
- 条目级置信度整体仍为 `estimated`——参数级有出处，不等于整条案例被官方背书。
