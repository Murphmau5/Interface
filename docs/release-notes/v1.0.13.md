# v1.0.13 — 首次使用引导

**发布类型**：使用体验发布版（首次启动三段引导 + 设置内重开）
**适用平台**：Windows 10 1803+ / Windows 11（x64）

## 版本亮点

1.0.10 把 78 条案例打进安装包，1.0.11 补齐键盘通道，1.0.12 让内容包能在线更新。但新装用户打开看到的仍是「七个域、几十个类目、一堆参数」，没有任何一句解释——不知道这是什么软件，也不知道三栏各管什么。这一版补上首次使用的第一段路。

### 1. 首次启动自动出现，可随时跳过

- 引导只在**首次启动**出现一次，三段式，右上角 `×` 与底部「跳过」都能立即退出。
- 跳过或看完都会写入本地标记，不会下次再弹。

### 2. 三段各说一件事

| 步骤 | 说什么 |
|---|---|
| 第 1 步 · 用途 | 这里存的是**规格**，不是链接；`verified` 有原始规格可核对，`estimated` 是推测，判断能不能直接用看参数与标记 |
| 第 2 步 · 三栏 | 左栏定范围（附当前各内容域真实条数）、中栏挑条目（搜索与四维筛选）、右栏看与调 |
| 第 3 步 · 参数 | 参数改了就生效，没有「保存」按钮，改动直接写入本机数据库，重启还在 |

引导只讲怎么用，不讲功能卖点。

### 3. 演示用真实数据

- 第 1 步的卡片、第 3 步的参数示例都取自当前库里的真实条目，不是占位图。
- 库里没有案例时显示「库里还没有案例」，不会伪造内容。

### 4. 设置里可以重新打开

- 设置 → 使用引导：显示当前记录状态（已看完 / 已跳过 / 尚未记录），一个按钮重新打开。
- 重开后再次看完或跳过，会覆盖之前的标记。

### 5. 引导是模态的

打开期间 `Esc` 只关闭引导；`Ctrl+K`、`Ctrl+N`、`Ctrl+E`、`/` 等全局键不会穿透到下层界面。

### 6. 标记写在本地

`ui.onboarding` = `v1:done` / `v1:skipped`，存于本机 settings 表，不联网、不随内容包更新。

### 7. 回归覆盖

- `scripts/ui-shot/onboarding-check.mjs`：13 项断言，覆盖首启只出现一次、三段推进、跳过与看完写标记、设置重开、深浅两套主题渲染、模态按键隔离。
- 既有 `scripts/ui-shot/palette-check.mjs` 12 项仍全过。
- 静态门：`tsc --noEmit`、`eslint .`、`vite build`、许可证白名单全过。

### 8. 真窗口验收仍未复测

标题栏拖动、双击最大化 / 还原、边缘吸附、原生拖拽导入、安装器单屏交互这些只在真窗口里成立的项，本轮仍未实测；清单与一键脚本随版本保留在 `docs/acceptance/real-window-checklist.md`，等统一开窗时一次跑完。
