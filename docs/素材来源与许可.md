# 素材来源与许可

> 本文件是发布前审计依据。口径：**凡未自绘即不得入库；标注「用户导入」的素材必须记录入库来源。**
> 最近更新：2026-11-08

## 1. 登记口径

| 来源类型 | 是否可入安装包 | 是否可入用户库 | 登记要求 |
|---|---|---|---|
| 自绘（HTML/CSS/JS 或 React 规格） | 是 | 是 | 记录作者、文件路径、许可（本项目 MIT） |
| CC0 / 公共领域 | 是 | 是 | 记录原始来源 URL、许可文本、获取日期 |
| OFL 字体 | 是 | 是 | 记录字体名、版本、OFL 文本 |
| 用户导入 | 否 | 是 | 记录入库来源（URL / 本地文件说明）、导入时间；提示用户自行确认权利 |
| 第三方站点截图（Dribbble / Mobbin / Behance 等） | **否** | 仅元数据 + 链接 | 不得缓存原图入包；不得随导出包分发 |
| 第三方插画 / 录屏 | **否** | 否 | 一律禁止 |

## 6. 未决冲突：GSAP 许可

- 事实：GSAP 3.13 起对商业使用免费，但其许可为 GreenSock 自有许可，**不在本项目白名单**（MIT / Apache-2.0 / BSD / ISC / OFL），且含「不得用于竞争产品」等限制。
- 与不可协商条款冲突：白名单禁止「任何带商用限制的许可」。
- 建议处理：
  1. **V1 预览运行时只用 CSS / WAAPI**，不引入 GSAP；
  2. 若确有案例必须 GSAP，则改为「用户导入的可选运行时」或单独申请例外，**默认不打包**；
  3. 该冲突记入 `DECISIONS.md` D-025，待用户裁决。
- 当前状态：外壳已定不引入 GSAP；预览运行时原计划「可选 GSAP」需按本条收紧。

## 7. 用户导入素材的处理

- 导入时弹一次确认：用户需自行确认素材权利；软件只做本地存储与展示。
- 数据库记录 `case_assets.origin = 'user_import'`，并要求填写来源说明。
- 导出包默认**只导出元数据与自绘素材**；用户导入的第三方原文件不自动嵌入。
- 删除案例只解除关联，不擅自删除用户原文件目录（除非用户显式清理）。
