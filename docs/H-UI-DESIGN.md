# H. 主界面 UI 设计方案（界序 INTERFACE）

> 版本：v0.1.1 · 2026-11-08 · 状态：设计基线（部分条款已定，见标注）
> 视觉立场：**仪器台 / 工作台**，不是后台管理系统，也不是素材展厅。
> 界面主标题建议「界序」+ 副标「INTERFACE」；`UI Motion Lab` 仅内部代号。
> 参考图：[artifacts/reference/深色动效设计灵感库.png](../artifacts/reference/深色动效设计灵感库.png)

## 3. 左栏导航

### 3.1 结构（推荐版本，含主题域，待确认）

```
内容域
  风格 Style           shortcut 1
  动效 Motion          shortcut 2
  交互反馈 Feedback     shortcut 3
  UI 组件 Components    shortcut 4
  主题 Theme *          （待确认，推荐独立）
工具位
  AI 工作台
  AI 发现
  设置
──────────────
我的收藏
最近使用
```

- 无「首页 Dashboard」「知识库管理」独立项：库默认视图由标识/「库」入口进入，合并展示统计、最近、待审核。
- 收藏与最近是**视图**，不是分类；置于底部，与域分组用 1px 分割线隔开。
- 每项右侧显示计数（仅内容域）；计数受当前细化筛选影响，但不受 `activeType` 自身影响（避免选中后数字跳变）。

### 3.2 若主题不独立（降级版本）

内容域保持 4 项；主题作为「风格」下的二级分段（风格 / 主题），底部条带的「主题」改为该分段内的筛选或隐藏。详见 D-017。

### 3.3 状态

| 状态 | 表现 |
|---|---|
| 默认 | textSecondary，透明底 |
| hover | textPrimary，surfaceRaised 底，120ms |
| 选中 | textPrimary，accentSoft 底，左侧 2px accent 竖线 |
| focus-visible | 2px focusRing，外扩 2px |
| disabled（主题未确认） | textTertiary + 右侧小圆点 + tooltip |

### 3.4 导航栈推入（已定，用户明确要求）

左栏是**导航栈**，不是一组跳页链接。点击一级域后，左栏内容整体向左移出，二级面板从右侧同步推入；中栏与右栏不参与位移，三栏总宽不变。

| 项 | 规格 |
|---|---|
| 触发 | 点击一级域（风格 / 动效 / 反馈与状态 / 组件 / 主题）；工具位不进入此栈 |
| 位移 | 距离 = 左栏当前实际宽度（含折叠态），只作用于左栏内容层 |
| 时长 | 240ms |
| 缓动 | `cubic-bezier(0.32, 0.72, 0, 1)` |
| 额外效果 | 不加缩放、不加模糊、不加阴影漂移 |
| 栈深 | 上限 2 层（域 → 类目）；类目再往下不在左栏继续套，落到中栏列表 |
| 返回 | 三路全部支持：顶部「‹ 返回」、`Esc` / `Alt+←`、触控板或触屏右滑手势 |
| 滚动还原 | 返回后还原域列表滚动位置与上次选中的类目 |
| 布局稳定 | 推入过程中三栏总宽不变，中栏与右栏不重排 |

二级面板结构：

```
‹ 返回
风格
收视觉语言、Token、风格家族、主题换皮；不收组件结构、交互行为、文案
────────────────────────
材质系                12
流派系                 8
平台系                 6
结构系                 5
色彩系统               …
```

- 标题即域名；标题区用一行小字说明该域「收什么、不收什么」，与底部条带的类型切分保持同一套口径。
- 类目行显示条目数；计数随细化条件变化，但不随 `activeType` 自身变化（避免选中后数字跳变）。
- 点击类目写入 `activeCategory`，中栏列表回到顶部并刷新；类目行同时成为中栏筛选摘要的第一段。
- 返回一级时清空 `activeCategory`，`activeType` 保持（域仍处于选中）。
- 若用户从底部条带切到另一个类型，左栏栈**自动回到一级**并同步高亮，避免「左栏停在旧域二级、列表已换类型」。
- 手势优先级：右滑仅在左栏区域内、且栈深 > 1 时拦截，不与中栏横向滚动、预览手势冲突。
- 无障碍：推入/返回通过 `aria-live` 播报当前层级；`prefers-reduced-motion` 下改为直接切换（无位移动画），返回键与 `Esc` 仍保留。

与底部条带的分工：

| 入口 | 管什么 | 状态 |
|---|---|---|
| 左栏导航栈 | 按域深入：风格 → 材质系 | `activeDomain` + `activeCategory` + 栈层 |
| 底部类型条带 | 按类型横切：全部 / 风格 / 控件 / 主题 / 动效 / 反馈 | `activeType` |

两者可叠加。叠加时必须在列表区头部用**筛选摘要**明示当前生效条件，例如：

```
风格 › 材质系 · 类型：控件 · 平台：桌面
```

摘要中每个条件可单独移除；移除后回到上一级条件，不清空其余条件。

## 4. 底部类型条带（核心新增）

### 4.1 位置与结构

- 位置：**列表区底部**，sticky，高 48px；上边 1px border，背景 surface，不使用浮层阴影。
- 结构：`[全部] [风格] [控件] [主题] [动效] [反馈]`，每项 = 可选图标 + 名称 + 计数。
- 选中指示器：一个共享滑块（accentSoft 填充 + 底部 2px accent 线），用 `transform: translateX()` 移动，180ms。
- 工具位页面（AI 工作台 / AI 发现 / 设置）不显示条带。

### 4.2 交互状态

| 状态 | 规格 |
|---|---|
| 默认 | 文字 textSecondary；计数 textTertiary；背景透明 |
| 悬停 | 文字 textPrimary；背景 surfaceRaised；圆角 8；120ms |
| 按下 | 背景 surface；文字 textPrimary |
| 选中 | accentSoft 背景；文字 accent；底部 2px accent 线；计数 textPrimary |
| 键盘焦点 | 2px focusRing，不改变选中态 |
| 禁用（主题待确认） | 文字 textTertiary；虚线 1px border；tooltip「主题域待确认」 |
| 溢出 | 横向滚动；左右各 24px 渐隐遮罩；hover 显示左右 chevron 按钮 |
| 滚动中 | 滑块固定于选中项，不随滚动漂移 |

窄窗口（列表区 < 560px）：只显示图标 + 计数，名称进入 tooltip；仍可横向滚动。

### 4.3 与左栏、顶部搜索的关系（唯一状态模型）

- 只有一个类型状态 `activeType`（`all | style | component | theme | motion | feedback`）。
- 左栏内容域入口与底部条带**读写同一个状态**，选中态双向同步（D-018）。
- 左栏的二级类目是另一个维度 `activeCategory`（如「风格 › 材质系」），只写进细化条件，不产生第二个类型状态。
- 底部条带切换类型时，左栏导航栈回到一级（§3.4），`activeCategory` 清空，避免旧域类目继续生效。
- 顶部搜索、平台、审核状态、置信度、组件层属于**另一组细化条件**，叠加在 `activeType` 之上，互不互斥。
- 清空筛选时：`activeType` 回到 `all`，`activeCategory` 与细化条件全部清除；搜索词保留直到用户清除（可在设置改）。
- 进入某个域详情或工具位时，条带隐藏或保持只读，不产生第二个筛选状态。

示例：

```
左栏「动效」→ activeType=motion，条带「动效」选中
条带点「控件」→ activeType=component，左栏切到「UI 组件」
顶部搜「侧边栏」→ 在 activeType 结果内再过滤
再选平台=桌面 → 三个条件叠加（类型 + 关键词 + 平台）
```

## 5. 列表区

### 5.1 头部

- 标题（当前域或「全部案例」）+ 结果数 + 当前筛选摘要。
- 右侧：网格/表格切换（分段控件 64×32）、排序下拉、清空筛选。

### 5.1.1 搜索框（双作用域，已定）

| 状态 | 表现 |
|---|---|
| 默认（本地） | 输入即出本地结果；左侧显示「本地库」标签；`Enter` 立即刷新本地结果 |
| 输入中 | 占位「搜索案例、标签、风格、提示词…」；不做实时网络请求 |
| 本地有结果 | 主列表正常展示；不出现联网入口干扰 |
| 本地无结果 | 列表底部提示条「要不要联网找找？」+ 按钮；**必须点击才联网** |
| 联网触发 | `Ctrl+Enter` 或点击提示；顶部出现临时状态「正在联网…（可取消）」 |
| 联网结果 | 独立区域「网络候选 · 未审核」，每条显示来源域名、作者（可确认时）、发现时间、类型猜测；**不混入主列表、不参与本地排序** |
| 未配置搜索 Key | 联网入口显示为「粘贴网址抓取该页面」；点击后输入 URL，走本地抓取预览，不依赖 Key |
| 错误 | 401/403/429/超时用中性提示，不打断本地结果 |

- 搜索框只有一个；作用域是**显式切换**，不是两个输入框。
- 网络候选必须经审核才进正式库；审核动作在候选卡片上，不在主列表。
- 搜索摘要与左栏类目、底部条带叠加时，仍按 §3.4 的可逐项移除摘要展示。
- 筛选行：平台、审核状态、来源、置信度、组件层（仅组件域）、双快照（仅风格/主题）。

### 5.2 网格视图（默认）

- 卡片最小宽 200；gap 16；列数随可用宽自适应（2–4）。
- 卡片结构：缩略图区（4:3，圆角 12，内描边）+ 名称 + 类型/平台小标签 + 置信度芯片 + 收藏图标。
- 缩略图优先展示真机截图；无截图时展示预览首帧；都没有则显示类型占位图（不允许用装饰性假图冒充案例）。
- 双击打开详情；单击选中并加载右侧预览。
- hover：整体上移 1px，border 变 borderStrong，阴影 shadowMd；不放大图片。
- 选中：1px accent 边框 + accentSoft 外发光（极克制，2px）。
- **万级数据**：虚拟滚动（只渲染视口内 ± 1 屏）；分页 40 条；缩略图按容器尺寸选 128/256/512 档；滚动时销毁悬停预览。
- 导出入口在列表区头部：一次点击同时导出 Markdown + JSON，文件名带版本与日期。

### 5.3 卡片悬停自动预览（已定，用户明确要求）

- 静态缩略图只是首帧；鼠标进入卡片后延迟 **140ms** 触发该案例的动效播放。
- 移出立即停止并回到首帧，**不得冻结在半路**。
- 全局同一时刻只允许一个悬停预览存活；列表滚动、切换筛选、打开详情时立即销毁。
- 键盘 `Tab` 聚焦等同悬停触发（同样 140ms 延迟）。
- 实现为**共享悬停预览层**：整页一个容器，跟随当前卡片定位；切换卡片只换内容，不重建容器。
- **禁止**每张卡片各挂一个 iframe / WebGL 上下文；列表内不常驻任何渲染实例。
- 遵循 `prefers-reduced-motion`：开启减少动效时只播一次，不循环。
- 主题类条目的「动效」定义为深浅交叉淡入：悬停时播放该主题的换皮效果，而不是并排静态双图。
- 悬停层与右栏完整预览共用**同一个播放内核**，只是参数集不同：
  - 悬停层固定「自动播放、单次、默认参数、卡片尺寸」；
  - 右栏可调全部参数（速度、持续、缓动、距离、状态、视口）。
- 悬停层不播放声音、不加载远程资源；资源缺失时显示首帧 + 「无预览」角标，不伪造动效。

### 5.4 表格视图（清单核对）

用于「收集完一批后逐条核对」。列：

| 列 | 内容 |
|---|---|
| 名称 | 名称 + 编号 |
| 类型 | 风格/动效/反馈/组件/主题 |
| 平台 | 桌面/手机/Web |
| 置信度 | 四态小结（如 `2✓ 3≈ 1?`） |
| 来源 | 站点名/手动 |
| 状态 | 已入库/待审核/已拒绝 |
| 更新时间 | 相对时间 |
| 收藏 | 星标 |

- 行高 44（舒适）/ 36（紧凑）；表头 sticky；支持列排序与多选批量操作（收藏、归档、删除需确认）。
- 表格不使用斑马纹；用 1px 行分隔线（border）保持仪器台感。

## 6. 详情区（预览为核心）

### 6.1 结构

```
[名称] [编号] [类型] [置信度小结] [收藏] [更多]
┌ 预览窗（sticky 顶部） ─────────────────────┐
│ 视口切换：手机 390×844 / 桌面 1280×800     │
│ [播放] [重播] [循环] [速度] [进度]          │
└────────────────────────────────────────────┘
参数面板（按 kind 分支）
  ├ 时长 420ms  [≈ estimated]
  ├ 缓动 cubic-bezier(...) [≈]
  ├ 距离 16px [✎ user_defined]
  └ 状态 / 视口
描述 / 适用场景 / 视觉特征 / 交互逻辑
来源（URL、站点、作者、时间、权限）
关联案例（uses_motion / uses_feedback …）
提示词（页签：通用 / CSS / React / …）
```

### 6.2 预览控制（必须真实生效）

- 播放 / 暂停 / 重播 / 重置 / 循环。
- 速度 0.25×–3×；持续时间直接改 `durationMs`；缓动预设 + 自定义 cubic-bezier；运动距离。
- 状态切换（如 default/hover/pressed/open/closed）。
- 视口手机/桌面；缩放适配窗口，不改变案例内部尺寸。
- 每次改动即时反映；若运行时能力不支持，控件禁用并说明原因，不做假开关。

### 6.3 参数与置信度芯片

| 级别 | 形态 |
|---|---|
| `verified` | 实线描边 + 对勾符号；hover 显示来源（原始 CSS/实测） |
| `estimated` | 虚线描边 + `≈`；hover 显示「AI 推测，建议实测」 |
| `user_defined` | 实线描边 + 铅笔符号 |
| `unknown` | 点线描边 + `?`，值为空或「未知」 |

- 芯片只使用灰阶 + 形状/符号区分，避免彩色语义污染；`estimated` 可在详情面板内使用极淡警告底（可选，待确认）。
- 参数修改后自动转为 `user_defined`，并保留原值与来源作为证据（可查看）。

### 6.4 风格/主题详情：双快照

- 强制并排：左 Light、右 Dark（浅色在左是行业习惯，可按用户偏好反转，待确认）。
- 双快照优先使用**两套真实渲染实例**（同一案例、同一状态、同一缩放），保证「组件预览是真实渲染」；两实例独立沙箱、同一参数通道。
- 性能不足或案例资源过重时，可降级为预生成的 light/dark 静态快照，但必须在角落标注「静态快照」，不得冒充实时渲染。
- 两套快照同尺寸、同状态、同缩放；标签固定在各自左上角。
- 单击任一侧放大；放大时不隐藏另一侧入口（顶部切换）。
- 双快照是功能，不提供「只显示深色」的默认配置。

### 6.5 组件详情（atoms / patterns 分支）

- atoms：形态、状态、Token、尺寸、用法；参数面板以状态切换为主。
- patterns：额外展示
  - 出现位置：顶部 / 底部 / 内联 / 浮层 / 全屏
  - 生命周期：常驻 / 临时 / 可关闭
  - 停留与消退时间（带置信度）
  - 点击与关闭行为
  - 配套动效、配套反馈（关联引用，可点击跳转）
- 顶部胶囊通知示例布局：预览中把它放在模拟状态栏下方，便于看位置与消退。

## 7. 设计 Token

### 7.1 语义层（只定义一次）

`bg / bgInset / surface / surfaceRaised / surfaceOverlay / border / borderStrong / textPrimary / textSecondary / textTertiary / accent / accentPressed / accentSoft / onAccent / focusRing / shadow / radius / spacing / typography`

### 7.2 主题层取值

| Token | 深色（推荐工作场景） | 浅色（完整对等） |
|---|---|---|
| `bg` | `#0A0C0E` | `#EDF0F6` |
| `bgInset` | `#060809` | `#E3E7EF` |
| `surface` | `#11151A` | `#FFFFFF` |
| `surfaceRaised` | `#171C22` | `#F6F8FC` |
| `surfaceOverlay` | `rgba(8,10,12,0.72)` | `rgba(237,240,246,0.80)` |
| `border` | `rgba(255,255,255,0.06)` | `rgba(16,24,38,0.10)` |
| `borderStrong` | `rgba(255,255,255,0.12)` | `rgba(16,24,38,0.18)` |
| `textPrimary` | `#E7ECF1` | `#101826` |
| `textSecondary` | `#93A0AC` | `#5A6478` |
| `textTertiary` | `#66727E` | `#7E8A9C` |
| `accent` | `#7FD3E8` | `#0E7A8A` |
| `accentPressed` | `#A6E3F3` | `#0A6272` |
| `accentSoft` | `rgba(127,211,232,0.12)` | `rgba(14,122,138,0.10)` |
| `onAccent` | `#06232A` | `#FFFFFF` |
| `focusRing` | `rgba(127,211,232,0.45)` | `rgba(14,122,138,0.35)` |
| `shadowSm` | `0 1px 2px rgba(0,0,0,0.55)` | `0 1px 2px rgba(16,32,48,0.08)` |
| `shadowMd` | `0 8px 24px rgba(0,0,0,0.50)` | `0 8px 24px rgba(16,32,48,0.12)` |
| `inset` | `inset 0 1px 2px rgba(0,0,0,0.50)` | `inset 0 1px 2px rgba(16,32,48,0.06)` |

规则：

- 中性灰两套统一往冷蓝偏移（hue ≈ 220），浅色不发灰发脏。
- 深色强调色浅青、面积可略大；浅色强调色深青、面积更小（避免浅底上刺眼）。
- 应用外壳里的 accent 只允许出现在「当前状态」与「主行动」两处；禁止装饰性使用。
- 1px 描边是结构的一部分，不允许用纯色块无缝拼接。

### 7.3 状态色（扩展，待确认 Q-04）

| Token | 深色 | 浅色 | 使用范围 |
|---|---|---|---|
| `statusSuccess` | `#5FD3A6` | `#0F7A5C` | 仅反馈案例内容、表单校验、审批结果 |
| `statusWarning` | `#E8C56A` | `#8A6100` | 同上 + `estimated` 芯片可选底 |
| `statusDanger` | `#F08A8A` | `#B3363F` | 同上 + 危险操作按钮 |
| `statusInfo` | `#7FD3E8` | `#0E7A8A` | 同上 |

约束：状态色不得用于导航、卡片装饰或大面积背景；应用外壳保持灰阶 + accent。

### 7.4 字体

```
--font-sans: "Inter", "HarmonyOS Sans SC", "Microsoft YaHei UI", system-ui, sans-serif;
--font-mono: "JetBrains Mono", "Cascadia Code", Consolas, monospace;
```

| 级别 | 字号/行高 | 字重 | 用途 |
|---|---|---|---|
| Display | 28/36 | 600 | 库默认视图大数字/标题 |
| H1 | 22/30 | 600 | 页面标题 |
| H2 | 18/26 | 600 | 区块标题 |
| H3 | 15/22 | 600 | 卡片/面板标题 |
| Body | 14/22 | 400 | 正文 |
| BodyStrong | 14/22 | 500 | 参数名、按钮 |
| Small | 12.5/18 | 400 | 标签、辅助 |
| Micro | 11/16 | 400 | 计数、编号 |
| Mono | 12.5/20 | 400 | 参数值、代码、URL |

- 标题字距 `-0.01em`；正文 `0`；数字使用等宽数字 `font-variant-numeric: tabular-nums`（参数表、计数）。
- 中文不回退到宋体；禁止用系统默认细字重做正文。

### 7.5 间距、圆角、尺寸

- 间距刻度：`2 / 4 / 6 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 48 / 64`。
- 圆角：`xs 4 / sm 6 / md 8 / lg 12 / xl 16 / pill 999`；卡片 12、面板 16、控件 8、芯片 pill。
- 控件高度：32（紧凑）/ 36（默认）/ 44（大触控）；桌面以 32/36 为主。
- 图标：16 / 20 / 24；线性图标，1.5px 描边。

### 7.6 阴影与镶嵌

- 深色阴影是「压暗」不是「发光」：`shadowMd` 黑色低透明。
- 镶嵌感：`inset` + 1px `border`；**不做双向凸起**。
- 禁止 `box-shadow` 彩色光晕、禁止 `filter: drop-shadow` 彩色发光。

## 8. 组件规范（基元）

| 组件 | 规格 |
|---|---|
| Button 主 | 实心 accent + onAccent 文字；高度 32/36；圆角 8；hover 提亮 8%；按下 accentPressed；禁用 40% 透明 |
| Button 次 | surfaceRaised + border；hover borderStrong |
| Button 危险 | 仅危险操作；statusDanger + 深底/浅底各一套；二次确认 |

## 9. 主题系统行为

1. 三态：跟随系统（默认）/ 深色 / 浅色。
2. 首次启动读取系统主题；**只有用户手动切换后才记住**。
3. 系统主题变化时，若处于「跟随系统」则实时切换；已手动选择则忽略。
4. 首屏防闪烁：窗口显示前由 Rust 侧读取设置/系统主题并注入根属性，前端不等待异步。
5. 强调色不直接取 Windows 强调色作为品牌色；系统强调色只作为可选参考（设置中可不采用）。
6. 双主题验收：每个界面两套截图；浅色必须验证「不发灰、不发脏、对比度达标」。
7. 预览内容不受应用主题强制影响：案例自身可指定亮/暗；风格与主题详情必须并排两套。

### 9.1 设置页结构（已定）

| 区块 | 内容 |
|---|---|
| 外观 | 主题三态（跟随系统 / 深色 / 浅色）；密度；列表默认视图 |
| 模型配置 | 服务地址 + 模型名 + API Key（默认 OpenAI 兼容，可接本地 Ollama）；测试连接；脱敏后四位；清除 |
| 搜索服务配置 | Bing / Tavily / Brave 分列，不与模型配置混排；测试连接；清除 |
| 预览 | 默认视口、循环、速度 |
| 存储 | 根路径、占用统计、备份/恢复 |
| 关于 | 版本、许可证、第三方声明、素材来源 |

- 模型配置与搜索服务配置**不得混排**。
- 测试连接错误区分：401 / 403 / 429 / 超时 / 额度不足；用中性文案，不弹红色阻断。
- Key 文案必须写「存储于 Windows 凭据管理器，不写入数据库、不写入日志、不随导出包导出」，**不得写「加密保护」**。
- 未配置 Key 时区块内显示「未配置」状态与配置引导，不隐藏区块。

## 10. 空、加载、错误状态

| 状态 | 表现 |
|---|---|
| 空库 | 三条可执行引导：导入图片 / 粘贴网址 / 让 AI 发现；并说明「安装包不含知识库内容，库由你逐步填充」；不使用插画占位冒充内容 |
| 空筛选结果 | 说明当前条件 + 「清除筛选」+ 放宽建议 |
| 加载列表 | 骨架屏（卡片形状，不做闪烁光带） |
| 预览加载 | 预览框内骨架 + 进度文案；超过 3s 显示「仍在加载」 |
| AI 未配置 | 入口可见并标「未配置」，点击进入设置引导；不隐藏、不清空数据、不用红色警告 |
| AI 失败 | 可见错误码与重试；不吞错 |
| 数据库异常 | 阻断式提示 + 备份恢复入口；不自动清库 |

## 11. 响应式与可访问性

- 最小窗口 1080×700；低于时允许横向滚动，不压缩到不可用。
- 左栏折叠、详情收起是两个独立开关；记住用户偏好。
- 键盘：`Ctrl+K` 聚焦搜索；`Alt+1..5` 切换域；`←/→` 在底部条带移动；`Esc` 清空搜索/关闭浮层；`Space` 播放/暂停（焦点在预览时）。
- 焦点环始终可见；不用 `outline: none` 裸奔。
- 正文对比度 ≥ 4.5:1；图形/大字号 ≥ 3:1。
- 支持 `prefers-reduced-motion`：外壳过渡降为 0ms 或仅淡入；预览案例需提供降级说明（不假装支持）。

## 12. 应用外壳动效

| 场景 | 时长 | 缓动 |
|---|---|---|
| hover / 按下 | 120ms | `cubic-bezier(0.32,0.72,0,1)` |
| 面板展开/收起 | 180ms | 同上 |
| 路由切换（淡入 + 4px 位移） | 180ms | 同上 |
| 详情区展开 | 240ms | 同上 |
| 左栏导航栈推入/返回 | 240ms | `cubic-bezier(0.32,0.72,0,1)`；位移 = 栏宽，无缩放/模糊 |
| 底部滑块 | 180ms | 同上 |
| 预览参数变化 | 由案例参数决定，外壳不额外加动画 |

- 只动 `transform` / `opacity`；不逐帧改宽高与布局。
- 禁止弹跳、霓虹拖尾、粒子装饰。

## 13. 主题域评估结论（写入 DECISIONS D-017）

| 方案 | 优点 | 代价 | 结论 |
|---|---|---|---|
| 独立成域 | 问题独立、数据结构独立、与底部条带一致、筛选直观 | 导航多一项；需明确与风格边界 | **推荐（待确认）** |
| 风格二级类目 | 导航不变 | 详情模板臃肿；条带「主题」入口尴尬；筛选困难 | 备选 |
| 不单列 | 最省 | 主题知识无法检索复用 | 不推荐 |

推荐做法：`kind=theme`，左栏增加「主题」，底部条带固定 5 类；主题详情复用双快照与 Token 覆盖展示，但独立参数面板。

## 14. 设计验收要点

1. 两套主题下所有界面截图通过对比度检查。
2. 底部条带 5 态（默认/悬停/选中/焦点/溢出）可复现。
3. 左栏与条带选中态永远一致；不存在两套筛选。
4. 参数改动能在预览中观察到；不能调时控件禁用并说明。
5. 置信度芯片在列表、详情、导出三处均存在。
6. 风格/主题详情并排双快照，不提供单主题默认。
7. 外壳无彩色发光、无大面积渐变、无假按钮。
8. 左栏推入 240ms、位移等于栏宽、无缩放模糊；「‹ 返回」/`Esc`/`Alt+←`/右滑四路均可返回，滚动位置与上次类目还原。
9. 悬停预览 140ms 触发、移出复位到首帧、全局唯一层、滚动即销毁、`Tab` 等效、`prefers-reduced-motion` 只播一次。
10. 同时使用左栏类目、底部条带与搜索时，列表头部显示完整筛选摘要，且每个条件可单独移除。
11. 全部界面文案为中文且来自集中词条表；组件内无硬编码文案。
