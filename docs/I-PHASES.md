# I. 七个开发阶段任务拆分

> 版本：v0.1.0 · 2026-11-08 · 状态：计划，未开始
> 规则：严格按阶段推进；每阶段结束必须运行类型检查、构建与适用测试；未验证不得声称完成。
> 编号：`P<阶段>-<序号>`；依赖阻塞项引用 `TASKS.md` 的 Q 编号。

## 依赖图

```
Phase 1 ─→ Phase 2 ─→ Phase 3 ─→ Phase 4
                    ↘ Phase 5 ─→ Phase 6 ─→ Phase 7
Phase 4 可与 Phase 5 并行（提示词模板不依赖 AI）
```

- Phase 4 的确定性模板不依赖 AI；AI 生成版在 Phase 5 接入。
- Phase 6 依赖 Phase 5 的分析与校验，不依赖 Phase 3 的预览运行时（但审核 UI 需要缩略图/快照能力，来自 Phase 3）。
- 每个阶段结束必须通过 J 文档对应验收，才允许进入下一阶段。
