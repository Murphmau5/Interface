# J. 每个阶段的验收标准

> 版本：v0.1.0 · 2026-11-08
> 原则：可观测、可复现、可留痕。未留证据的条目不视为通过；不得用「看起来没问题」替代验证。

## 专项验收（跨阶段）

### 双主题

- 每个页面在 dark/light 下均截图；浅色不发灰发脏；正文对比度 ≥ 4.5:1。
- 强调色面积：浅色主题不得出现大面积 accent 背景。
- 首屏无主题闪烁；系统主题变化在「跟随系统」下实时生效。

### 置信度

- 列表、详情、导出三处可见。
- 四态均可构造测试数据并正确展示。
- AI 路径无法产生 `verified`。
- 用户修改后变为 `user_defined`，原证据可查。

### 预览真实生效

- 时长/缓动/距离/速度/状态/视口六项逐项对比录屏。
- 媒体类案例明确标注不可调，不出现假滑块。

### 本地优先

- 清空 AI/搜索配置 + 断网：启动、搜索、预览、导出、备份全部可用。
- 所有外部失败有可读错误与重试入口。

### 数据安全

- 密钥不在数据库、日志、导出包、截图中出现。
- 删除/覆盖/导入等高风险操作有确认。
- 软删除可恢复；备份可恢复。
- 密钥文案不得出现「加密保护」；必须为「存储于 Windows 凭据管理器…」的准确表述。

### 左栏导航栈

- 推入位移 = 栏宽，240ms，`cubic-bezier(0.32,0.72,0,1)`，无缩放/模糊。
- 「‹ 返回」/`Esc`/`Alt+←`/右滑四路均可返回；返回还原滚动位置与上次类目。
- 推入过程中三栏总宽不变，中栏与右栏无重排。
- 从底部条带切类型时，左栏回到一级且高亮同步。

### 悬停自动预览

- 悬停 140ms 后播放；移出立即复位首帧，不停在半路。
- 全局同时只有一个悬停预览；滚动/筛选/打开详情即销毁。
- `Tab` 聚焦等效触发；`prefers-reduced-motion` 只播一次。
- 列表卡片内无常驻 iframe/WebGL 上下文。

### 中文搜索

- 「卡展」可命中「卡片展开动效」；2 字查询有分词 + `LIKE` 兜底。
- `kzpk` 可命中「卡片展开」。
- 排序符合：完全匹配 > 标题 > 标签 > 描述；同档按最近使用/收藏。
- 覆盖名称、描述、标签、平台、类型/域、风格名、提示词、来源站。

### 双作用域搜索

- 默认只搜本地，输入不触发任何网络请求（可用断网验证）。
- `Enter` 搜本地，`Ctrl+Enter` 走联网；两者结果不混排。
- 联网结果标注「网络候选 / 未审核」，显示来源域名、作者（如有）、发现时间。
- 本地无结果时必须点击「要不要联网找找？」才发起请求。
- 未配置搜索 Key 时联网入口为「粘贴网址抓取该页面」，且该路径可用。
- 候选存于 `candidates`，审核通过才生成 `cases`。

### 许可与合规

- `LICENSE` 为完整 MIT 原文，仅含年份与署名补充。
- `cargo-deny` 与前端许可检查可失败阻断；无 GPL/AGPL/LGPL/SSPL 依赖。
- 安装包内无第三方截图/插画/录屏；示例素材全部自绘。
- 字体仅系统栈或 OFL；Lucide 声明保留。
- 用户导入素材不随导出包自动嵌入。
- 安装包不含知识库内容；首装为空库并可完成首次填充。
- 官方内容包（如发布）只含自绘演示与元数据。

### 大数据量与审核

- 1 万条库下列表可滚动，虚拟滚动生效，内存不随条目线性增长。
- 分页 40 条，缩略图按 128/256/512 档命中。
- 搜索在万级库下首屏 ≤ 300ms。
- 一切外部来源只能进候选池；不存在免审设置；定时补充也必须人工确认。
- 导出一次同时生成 `.md` 与 `.json`，内容一致，文件名含版本与日期，置信度标记不丢失。

### 发布与仓库

- 仓库名为 `Interface`（public），默认分支 `main`。
- `.gitignore` 覆盖 `target/`、`node_modules/`、`.agent/temp`、本地数据库与素材目录。
- Release 附件含安装包与 SHA-256；发布说明在 `docs/release-notes/`。
- README 首行明确「v1.0.0 · 初始框架预览版」。
